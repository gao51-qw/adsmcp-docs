Every client uses `https://mcp.adsmcp.si/mcp` and your own AI model. Claude, ChatGPT and clients with a `localhost` sign-in callback use OAuth; all others use an API key (`sk_live_...`). ADSMCP is not listed in any app's directory, so you always add it yourself. Overview: [Add to your agent](/add-to-your-agent).

Start with the [quickstart](/quickstart) if you have not connected an ad account yet.
