Look up TikTok targeting values by targeting_type: interest_categories (get_tiktok_interest_categories), interest_keywords (get_tiktok_interest_keywords; needs keyword), regions (get_tiktok_regions) or languages (get_tiktok_languages). action_categories, carriers and device_models are not available yet and are refused. Without targeting_type, a keyword (or query) runs the interest keyword search. Documented parameters the underlying tool does not take are accepted and listed in ignored. Read-only.

**Platform:** TikTok Ads · **Type:** Read
