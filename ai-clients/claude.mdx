## Setup (2 Minutes)

There are two listings in Claude's directory, and both connect to the same ADSMCP account. The **connector** gives Claude the 400+ tools. The **plugin** installs that same verified connector and adds ADSMCP's 15 skills, 5 slash commands, and a performance marketing agent. You don't need both.

**Connector (verified)**

**1. Search Claude's directory for ADSMCP**

Open [Customize → Connectors](https://claude.ai/customize/connectors), make sure **Discover** is selected, and type **ADSMCP** in the search box. Pick **ADSMCP Ads & Performance Marketing Agent** by ADSMCP. It's the one with the verified badge.

![Claude Customize page with the Connectors tab and Discover selected, showing ADSMCP Ads & Performance Marketing Agent by ADSMCP with a verified badge in the search results](/images/PuyhsbFPuRU-UDud/images/claude/directory-search.png)

Search Customize → Connectors → Discover for ADSMCP

Or go straight to the [ADSMCP listing](https://claude.ai/customize/connectors/id/adsmcp-ads-performance-marketing-agent).

**2. Click Connect to Claude**

On the listing, click **Connect to Claude**. Hover the badge next to the name to see *"Verified — Anthropic has reviewed this connector for quality and security."*

![ADSMCP Ads & Performance Marketing Agent listing in Claude with the tooltip 'Verified — Anthropic has reviewed this connector for quality and security' and the Connect to Claude button](/images/PuyhsbFPuRU-UDud/images/claude/connector-verified.png)

The ADSMCP listing in Claude, with the verified badge and the Connect to Claude button

**3. Sign in to ADSMCP**

Your browser opens ADSMCP's sign-in page. Sign in (or create an account) and approve Claude. Authentication is OAuth, so Claude never sees your ad platform passwords.

If you close the window early, Claude shows **You started connecting...but didn't finish**. Click **Connect** on that screen to pick up where you left off.

![Claude connector screen explaining that the ADSMCP connection was started but not finished, with a Connect button to resume](/images/9neHVIcd-r_femLX/images/claude/connection-resume.png)

Resume the connection if sign-in was interrupted

**4. Connect your ad accounts**

Link the platforms you want Claude to manage at [adsmcp.ai/connections](https://adsmcp.si/dashboard/connections). Claude can only reach accounts you've connected there.

**5. Check the connection**

Under **Customize → Connectors → Yours**, **ADSMCP Ads & Performance Marketing Agent** shows a checkmark in the **Status** column.

![Claude Connectors page showing ADSMCP Ads & Performance Marketing Agent with a connected status checkmark](/images/9neHVIcd-r_femLX/images/claude/connector-connected.png)

The checkmark confirms that ADSMCP is connected

**Plugin (connector + skills)**

**1. Search Claude's plugins for ADSMCP**

Open [Customize → Plugins](https://claude.ai/customize/plugins), select **Discover**, and search for **ADSMCP**. The listing says **from Anthropic Directory**.

Or go straight to the [ADSMCP plugin](https://claude.ai/customize/plugins/id/7bb5ea42-d7d7-4256-89d7-5798f5dc9c83%40anthropic-plugin-directory).

![ADSMCP plugin listing in Claude, from Anthropic Directory, with tabs for Skills 15, Commands 5, Connectors 1, and Agents 1 and an Add button](/images/PuyhsbFPuRU-UDud/images/claude/plugin-directory.png)

The ADSMCP plugin: 15 skills, 5 commands, 1 connector, and 1 agent

**2. Click Add**

Click **Add**. The plugin installs **ADSMCP Ads & Performance Marketing Agent** (the verified connector) along with the skills, commands, and agent.

**3. Sign in to ADSMCP**

When Claude asks you to connect, sign in to ADSMCP in your browser and approve Claude. Then link your ad platforms at [adsmcp.ai/connections](https://adsmcp.si/dashboard/connections).

> [!TIP]
>
> The plugin is the same install you use in [Claude Cowork](/ai-clients/claude-cowork). Skills teach Claude ADSMCP's workflows: research before creating, validate before launching, and confirm before spending. They load automatically when your request matches.

## FAQ

> **Do I need to add a custom connector or paste the MCP URL?**
>
> No. ADSMCP is an Anthropic-verified connector, so you add it by searching Claude's directory. Don't use **Add custom connector**. The directory listing connects to the same server, always has the latest tools, and in the plugin form also includes ADSMCP's skills, commands, and agent. If you added ADSMCP as a custom connector before it was listed, remove that one and connect the verified listing so Claude doesn't see two copies of every tool.

> **Is it a connector or a plugin?**
>
> Both exist, and both come from ADSMCP through Anthropic's directory. **ADSMCP Ads & Performance Marketing Agent** is the verified connector: the 400+ tools. The **ADSMCP** plugin installs that connector plus 15 skills, 5 slash commands, and an agent. Use the connector for chat. Use the plugin if you want the skills and commands, or if you work in [Cowork](/ai-clients/claude-cowork).

> **What are Claude connectors?**
>
> Claude connectors (powered by MCP — Model Context Protocol) allow Claude to securely connect to external services and take actions on your behalf. Anthropic created MCP as an open standard for AI tool integration. **ADSMCP Ads & Performance Marketing Agent** enables advertising management across Google Ads, Meta Ads, Amazon Ads, ChatGPT Ads, LinkedIn Ads, and TikTok Ads.

> **Which Claude plans support connectors?**
>
> MCP connectors are available on Claude Pro, Max, Team, and Enterprise plans. The free tier does not include connector functionality. Claude Code (for developers) also supports MCP on paid plans.

> **What makes Claude different from ChatGPT for ads?**
>
> Claude was created by Anthropic, who also developed MCP. This means the deepest integration, including progress streaming that shows real-time updates during campaign creation. Claude also naturally invokes tools without explicit prompting, while ChatGPT may need you to mention specific tools by name.

> **Can I also use Claude Code?**
>
> Yes. Claude Code is the terminal-based developer tool that also supports MCP. See the full [Claude Code Setup Guide](/ai-clients/claude-code) for the one-command setup. Both Claude (chat app) and Claude Code connect to the same ADSMCP MCP server.

> **Can I use ADSMCP with both Claude and ChatGPT?**
>
> Yes. Your ADSMCP account works across all supported AI clients. Connect **ADSMCP Ads & Performance Marketing Agent** from Claude's directory and install the ADSMCP plugin from ChatGPT's **Plugins** directory. Your ADSMCP account and ad platform connections carry across both.

> **How much does this cost?**
>
> ADSMCP pricing is based on tool calls, not ad spend. Free tier: 15 calls/month. Plus: $49/mo for 150 calls. Pro: $99/mo for 600 calls. Max: \$199/mo for 3,000 calls. See [full pricing](https://adsmcp.si/pricing).

> **Tools aren't working or I see connection errors. What do I do?**
>
> If no ADSMCP tools work at all (even basic ones like checking connections), follow these steps:
>
> 1. **Check tool permissions:** When Claude prompts you to allow a tool, make sure read tools are set to **Always allow** and write tools to **Custom** (ask each time). If you accidentally blocked tools, go to **Customize → Connectors**, find **ADSMCP Ads & Performance Marketing Agent**, and reset permissions.
> 2. **Reconnect the connector:** Go to **Customize → Connectors**, disconnect **ADSMCP Ads & Performance Marketing Agent**, then connect again and complete the OAuth flow.
> 3. **Refresh your ADSMCP session:** Go to [adsmcp.ai](https://adsmcp.si), log out, log back in, then return to Claude.
>
> Claude web connectors may disconnect every 1–2 weeks — this is normal. Just re-enable and re-authenticate when it happens.
>
> See [Troubleshooting FAQ](/knowledge-base/faq#troubleshooting) for more details.
