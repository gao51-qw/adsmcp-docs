Both surfaces use `https://mcp.adsmcp.si/mcp`. The full Agent Pack installer is the Codex CLI path.

## Codex CLI

```bash
codex mcp add adsmcp --url https://mcp.adsmcp.si/mcp
```

From a checkout of this repo, install the pack with `node ./bin/adsmcp-agent.mjs install --client=codex`. That places the agent prompt, the five skills, and the rule that blocks direct ad-platform API calls.

Use `/adsmcp:setup`, `/adsmcp:performance-review`, `/adsmcp:write-ad-copy`, `/adsmcp:wasted-spend`, and `/adsmcp:campaign`.

If a Codex surface uses skill files instead of slash commands, the matching files are under `.skills/adsmcp/`.

## Codex Desktop

Desktop setup is on [Codex Desktop](/ai-clients/codex-desktop). Use the same remote URL. There is no second plugin. Spend changes still wait in [Approvals](/approvals).

First request: see the [quickstart](/quickstart).
