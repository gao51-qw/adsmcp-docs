Plan a reallocation of Sponsored Products daily budgets between enabled campaigns from their ROAS and budget utilization. Read only: it changes nothing; the plan lists decreases and pauses first. Apply by staging update_amazon_sp_campaign_budget per campaign. Reads a live Amazon Reporting v3 report (14-day attribution): if Amazon has not finished it the result is status 'pending' with a report_id and no rows; call again with that report_id. Sponsored Products only; the date window is at most 31 days.

**Platform:** Amazon Ads · **Type:** Read
