---
title: "Grok"
description: "Add ADSMCP as a remote MCP server in Grok."
---

Add a remote MCP server named `adsmcp` with URL `https://mcp.adsmcp.si/mcp`. Use hosted OAuth when the client offers it. If it asks for a header, set `Authorization: Bearer YOUR_API_TOKEN` from [API Keys](https://adsmcp.si/dashboard/api-tokens).

Grok does not install a separate marketplace plugin. Ask in plain language for setup, a performance review, ad copy, a wasted-spend audit, or a paused campaign. The tool order is [Workflows](/workflows).

The docs search server at `https://docs.adsmcp.si/mcp` is only for reading these pages. It is not the ad server.

First request: see the [quickstart](/quickstart).
