The server URL is `https://mcp.adsmcp.si/mcp`. Claude on the web uses a custom connector. Claude Code also installs the Agent Pack and the five slash commands.

## Claude on the web

1. Open [claude.ai/customize/connectors](https://claude.ai/customize/connectors).
2. Add a custom connector named ADSMCP.
3. Server URL: `https://mcp.adsmcp.si/mcp`.
4. Complete the hosted login. If the form asks for a header instead, use a token from [API Keys](https://adsmcp.si/dashboard/api-tokens): `Authorization: Bearer YOUR_API_TOKEN`.

The install is that URL. Claude on the web does not load `/adsmcp:setup` or the other four slash commands. Ask for the workflow in a sentence. The tool order is [Workflows](/workflows).

## Claude Code

The terminal install, bearer header, and Agent Pack are on [Claude Code](/ai-clients/claude-code). Connect with:

```bash
claude mcp add --transport http adsmcp https://mcp.adsmcp.si/mcp
```

## If the call is refused

`claude.ai` and `claude.com`, including subdomains, are allowed `Origin` hosts. A request that omits `Origin` is also allowed.

After the handshake, a call with no bearer token returns HTTP 401, JSON-RPC `-32001`, reason `missing_token`. A token in the query string is rejected with `query_token_not_allowed`. The handshake itself runs before that check. See [MCP protocol](/mcp-protocol).

First request: see the [quickstart](/quickstart). Spend changes wait in [Approvals](/approvals).
