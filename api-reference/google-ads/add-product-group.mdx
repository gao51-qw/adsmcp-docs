Build a Standard Shopping ad group's product partition tree: split products by brand, category, product type, item id, condition, channel or custom label and bid on (or exclude) each partition. On an empty tree without dimension it creates the single 'All products' unit; with dimension it creates the root subdivision. Otherwise the named unit is subdivided (removed and re-created as a subdivision with the same parent and value, in the same approval): one unit per partition plus the required 'everything else' unit, which keeps the subdivided unit's own state unless you set it. Staged for dashboard approval; the approved replay re-reads the target first and refuses if it changed.
