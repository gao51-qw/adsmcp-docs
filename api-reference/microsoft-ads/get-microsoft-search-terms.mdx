Microsoft Ads search terms for a period (Search query performance report): the search term, the keyword that matched it, the delivered match type and metrics per row, plus totals. Microsoft includes only search terms with enough clicks. Metrics: impressions, clicks, spend, CTR (clicks / impressions), CPC, conversions, conversion value (revenue), cost per conversion, ROAS; money in the account currency (major units, `currency`). Totals cover every row of the report, rows are sorted by spend. If Microsoft is still building the report the result is status report_pending with a report_token. Read-only.

**Platform:** Microsoft Ads · **Type:** Read
