Check whether a Meta Pixel is firing and which events it records, from get_meta_pixel_events (Graph \<pixel_id\>/stats aggregated by event over Meta's default recent window). Returns the per-bucket rows plus a total count per event, and the counts for ViewContent, AddToCart and Purchase (0 when not seen), to confirm them before building a retargeting catalog campaign. A failed or unavailable read is returned unchanged as an error. Read-only.

**Platform:** Meta Ads · **Type:** Read
