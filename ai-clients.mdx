---
title: "Other AI clients"
description: "Connect Grok, Claude Cowork, Codex Desktop, and Muse to the ADSMCP remote MCP server."
---

These clients use the remote MCP server at `https://mcp.adsmcpserver.com/mcp`. They do not get a separate marketplace plugin. Full Agent Pack install remains Claude and Codex.

## Grok

Add a remote MCP server named `adsmcp` with URL `https://mcp.adsmcpserver.com/mcp`. Use OAuth when the client offers it.

## Claude Cowork

In the workspace connector settings, add `https://mcp.adsmcpserver.com/mcp`. There is no separate Cowork plugin.

## Codex Desktop

Use the same remote URL as Codex CLI: `https://mcp.adsmcpserver.com/mcp`. The full Agent Pack installer remains the Codex CLI path.

## Muse

Add a custom MCP connector with URL `https://mcp.adsmcpserver.com/mcp`. If the client asks for a header, use `Authorization: Bearer YOUR_API_TOKEN`.
