Resume (enable) Amazon campaigns of one ad_product (SP, SB or SD) with enable_amazon_\<product\>_campaign, one call per campaign (up to 20). The changes are queued for approval (execution_mode approval_required, the only mode accepted): each item is returned as staged and the campaign is enabled (starts spending) only after its queued action is approved and executed. ad_product is required. Items are reported one by one.
