Prepare the cards of an image carousel for create_tiktok_carousel_ad from 2-10 TikTok image ids, with one ad text and landing page per card (the first is reused when fewer are given). TikTok has no carousel-card object for image carousels, so nothing is created on TikTok and card_id is null; pass next_arguments to create_tiktok_carousel_ad. PRODUCT cards are not supported. Read-only.
