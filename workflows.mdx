These workflows are the supported way to use the agent. In Claude Code, Codex and OpenClaw they are slash commands (from the `adsmcp` plugin or the installer; see [MCP configuration](/mcp-setup#agent-pack-skills-and-slash-commands)). On other clients, ask for the same workflow in plain language. The tool order does not change by client. The workflows run on your own AI model.

Every workflow loads brand context and calls `get_connections_status` before a platform tool. Every change, on every platform, is staged and waits in [Approvals](/approvals) until a person approves it on the dashboard.

## `/adsmcp:setup`

Prepares the workspace.

1. Check `CLAUDE.md`, `STRATEGY.md`, and `MEMORY.md`.
2. Call `get_connections_status`.
3. Refresh brand and strategy files with `sync_brand_context` and `sync_strategy_context` only after you approve.
4. Report which platforms are connected and which command to run next.

If a required KPI is missing, later comparison workflows stop and send you back here. The agent does not fill in a default CPA, ROAS, CTR, or budget.

## `/adsmcp:performance-review`

Builds a cross-platform scorecard against `STRATEGY.md`.

1. Load context files.
2. Call `get_connections_status`.
3. Read metrics from each connected platform.
4. Compare spend, conversions, CPA, ROAS, CTR, and target deviation.
5. Return a scorecard and the top three recommendations.
6. Stage a Pending Action only after you pick a change. You approve it on the dashboard.

Use this when you want a health check, not a new campaign.

## `/adsmcp:write-ad-copy`

Drafts copy from the brand voice in `CLAUDE.md`.

1. Load banned terms, tone, and CTA preferences.
2. Ask for the platform, the objective, three to five keywords or themes, and the offer. The platforms for this command are Meta, Google, LinkedIn, and TikTok.
3. Call `get_connections_status` when the copy is for a live account.
4. Call `generate_ad_copy_ideas`. The tool returns constraints from the Meta KPI row. It does not return headlines. Your AI model writes five variants in the chat. The return fields are on [Analysis](/analysis).
5. Submitting a chosen variant is a separate create. Meta uses `create_ad` and does not cut the creative text. A responsive search ad uses `create_google_rsa_ad`. LinkedIn uses `create_linkedin_creative`. TikTok uses `create_tiktok_ad`, `create_tiktok_spark_ad`, or `create_tiktok_carousel_ad`. Field rules are on the platform pages linked from [Analysis](/analysis).
6. After an approved create, call `record_learning` for that confirmed outcome. What may be stored is on [Safety](/safety).

Copy in the chat is not a live ad.

## `/adsmcp:wasted-spend`

Finds spend that is not meeting the strategy thresholds.

1. Load the thresholds in `STRATEGY.md`.
2. Call `get_connections_status`.
3. Read spend, conversion, and fatigue results.
4. Rank findings by dollar impact.
5. Propose pauses, exclusions, or budget changes as Pending Actions.

The audit looks for spend with no meaningful conversions, enough history to leave the learning window, and a conversion goal. Awareness campaigns are out of scope for that cut.

## `/adsmcp:campaign`

Creates a campaign shell. It does not turn spend on.

1. Load context and strategy limits.
2. Call `get_connections_status`.
3. Validate objective, budget, targeting, assets, and tracking.
4. Stage the create. Once a person approves it on the dashboard, the campaign is created paused.
5. Turning the campaign on is a separate change that also needs approval, and is checked against the [spend cap](/safety#spend-cap).
6. Call `record_learning` for the confirmed outcome.

Platform create tools:

| Platform | Validate, then create paused |
| --- | --- |
| Google Ads | `validate_google_search_campaign_draft`, then `create_search_campaign`. Other types use `create_google_pmax_campaign`, `create_google_display_campaign`, `create_google_demand_gen_campaign`, `create_google_youtube_campaign`, `create_google_shopping_campaign`, or `create_google_app_campaign`. |
| Meta Ads | `create_campaign` (created `PAUSED`). |
| TikTok Ads | `validate_tiktok_campaign_draft`, then `create_tiktok_campaign`. |
| LinkedIn Ads | `validate_linkedin_campaign_draft`, then `create_linkedin_campaign`. |
| Amazon Ads | `get_amazon_profiles`, then `create_amazon_sp_campaign`, `create_amazon_sb_campaign`, or `create_amazon_sd_campaign`. |

A failed create stops. The agent explains the error and waits. It does not retry; a corrected attempt is a new change that needs a new approval.
