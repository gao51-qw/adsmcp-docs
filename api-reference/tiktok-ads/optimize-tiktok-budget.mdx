A daily budget plan across TikTok budget holders (campaigns with a daily budget; ad groups with a daily budget under campaigns without one): money moves from weak to strong holders within max_change_percentage, increases only where the holder spends its budget, zero-conversion holders far over the average CPA are PAUSE candidates. Changes nothing: apply_order lists decreases first, then increases, as update_tiktok_campaign / update_tiktok_ad_group / pause_* calls, each staged for dashboard approval and the account spend cap.
