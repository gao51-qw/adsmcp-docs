Organic Search Console queries next to Google Ads search terms for the same dates: one row per query text with its organic clicks, impressions, CTR and position and its paid clicks, impressions, cost, conversions and conversion value, marked both / organic_only / paid_only. Structured data only (no scoring); reads at most 5,000 queries and 5,000 search terms. Read-only.

**Platform:** Google Search Console · **Type:** Read
