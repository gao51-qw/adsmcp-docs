An ad ops agent is the five workflows plus a schedule. [Agent Studio](/agent-studio) shows whether the tenant is ready. A ready row does not enable a campaign.

## What you give it

1. A plain-language goal, such as "keep CPA under the target in `STRATEGY.md`."
2. Connected accounts and the account ids. See [Set up a project](/set-up-a-project).
3. A cadence from [Scheduled cadence](/scheduled-cadence): a weekly brief, a monitor, or an automation rule.

## What it does on each run

1. Load `CLAUDE.md` and `STRATEGY.md`.
2. Call `get_connections_status`.
3. Read the platforms in scope. `/adsmcp:performance-review` builds the scorecard. `/adsmcp:wasted-spend` flags spend that misses the targets.
4. Return findings. A suggested pause, budget change, or enable is a Pending Action.

The person approves or rejects that action. See [Approvals](/approvals). `resume_workflow_after_approval` returns `workflow_resume_not_supported` on this server. Continue in a new request with the approved action id.

Watch Agent on the admin screen scans about every 15 minutes and files the same kind of Pending Action. It is not a substitute for the workflow you named.
