Claude Cowork can run recurring tasks against ADSMCP. It reads and proposes; you approve on the dashboard.

## 1. Connect

Add ADSMCP as a custom connector on your Claude account ([Claude](/ai-clients/claude)) and enable it in Cowork.

## 2. Project instructions

Put this in the project instructions:

- The advertiser, the platforms in scope, and the account id for each.
- The KPI targets (or "read STRATEGY.md").
- *"Call get_connections_status first. Never assume an account id. Every change goes to ADSMCP Approvals; tell me what is waiting. Do not retry a failed change."*

## 3. Scheduled tasks

Good recurring tasks:

| Task | Tools |
| --- | --- |
| Monday scorecard | Platform performance reads, `generate_cross_platform_report` |
| Mid-month pacing | `analyze_budget_pacing` with the campaigns you pass in |
| Waste check | `analyze_wasted_spend`, `detect_creative_fatigue` |

## 4. What a scheduled task cannot do

A Cowork task cannot apply a change. Anything it proposes is staged as a pending action and waits until you approve it on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page. There is no "small changes apply automatically" mode. Budget changes and enables are also checked against your [spend cap](/safety#spend-cap) when you approve them.

Each tool call a task makes counts against your [plan](/pricing). See [Scheduled cadence](/scheduled-cadence).
