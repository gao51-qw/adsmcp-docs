## 1. Sign up

Create an account at [adsmcp.si](https://adsmcp.si). The Free plan includes 15 tool calls a month. See [Pricing](/pricing).

## 2. Connect an ad account

Open [Connections](https://adsmcp.si/dashboard/connections) and connect the platforms you use: Google Ads, Meta Ads, Amazon Ads, TikTok Ads and LinkedIn Ads sign in with OAuth; ChatGPT Ads takes the account's API key. See [Connect ad accounts](/connections).

## 3. Set your guardrails

- On [Brand](https://adsmcp.si/dashboard/brand), set your KPI targets and your **Max Daily Budget** (the [spend cap](/safety#spend-cap)).
- Optionally fill in [Business context](/business-context).

## 4. Connect your AI client

The MCP server is:

```text
https://mcp.adsmcp.si/mcp
```

| Client | How |
| --- | --- |
| Claude (web, Desktop, Cowork) | Add a custom connector with the URL; sign in with OAuth. [Steps](/ai-clients/claude) |
| ChatGPT | Add a custom connector (developer mode) with the URL; OAuth. [Steps](/ai-clients/chatgpt) |
| Claude Code | `claude mcp add --transport http adsmcp https://mcp.adsmcp.si/mcp`, or install the `adsmcp` plugin. [Steps](/ai-clients/claude-code) |
| Codex, Cursor, Gemini CLI, Windsurf, others | Add the URL with an `Authorization: Bearer sk_live_...` header from [API Tokens](https://adsmcp.si/dashboard/api-tokens). [All clients](/ai-clients) |

## 5. Make the first call

Ask your client:

```text
Call get_connections_status and tell me which ad platforms are connected. Do not change anything.
```

Then try a read, for example:

```text
Show last week's spend, conversions and CPA for my Google Ads campaigns.
```

## 6. Approve changes on the dashboard

When you ask for a change ("pause campaign X", "raise the budget to 50"), the client gets back a pending action. Open [Approvals](https://adsmcp.si/dashboard/approvals) to approve or reject it. Nothing changes in your ad account before that. See [Approvals](/approvals).
