Google Search Console, the docs' integration tool: action list_tools lists the Search Console reads (and the docs' write actions, which are not available); action execute runs one by tool_name (a native name such as get_search_console_performance or a docs action name such as google_search_console-retrieve-site-performance-data) with its arguments. Read-only.

**Platform:** Google Search Console · **Type:** Read
