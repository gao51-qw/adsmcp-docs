---
title: "Claude Cowork"
description: "Connect Claude Cowork to ADSMCP with the same remote MCP URL as Claude."
---

Claude Cowork is the desktop workspace, not the Claude Code terminal. In the workspace connector settings, add `https://mcp.adsmcp.si/mcp`.

There is no separate Cowork plugin and no slash-command pack. Describe the job in the project instructions, for example a weekly read of connected accounts that files recommendations and does not enable spend. Scheduled checks still create [Pending Actions](/approvals) for any change that can spend.

Use a bearer token from [API Keys](https://adsmcp.si/dashboard/api-tokens) only if the connector asks for a header.

First request: see the [quickstart](/quickstart).
