Spend, clicks, conversions, CTR, CPC and CPA per age and gender segment (TikTok AUDIENCE reports), ranked by CPA when the account converts and by CTR otherwise, with best / worst segments and a first-half / second-half saturation check. TikTok reports no conversion value per demographic, so there is no ROAS. Read-only; no advice.

**Platform:** TikTok Ads · **Type:** Read
