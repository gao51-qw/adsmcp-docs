## 2026-09-23

- Removed Snap Ads from new connections and the tool catalog. Existing stored rows are left in place.
- Amazon campaign performance reports now cover Sponsored Products, Sponsored Brands, and Sponsored Display. Pass `ad_product` as `sp`, `sb`, or `sd`.
- Added paused Google App campaign creation with `create_google_app_campaign`.
- Public report links at `/r/{token}` can show the tenant name and HTTPS logo.
- Each catalog tool has a REST page in the Tool reference tab.
