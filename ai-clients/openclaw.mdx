---
title: "OpenClaw"
description: "Add the ADSMCP remote MCP server to OpenClaw and use the five workflow names."
---

```bash
openclaw mcp add adsmcp --url https://mcp.adsmcp.si/mcp
```

If OpenClaw asks for a header, use a token from [API Keys](https://adsmcp.si/dashboard/api-tokens):

```text
Authorization: Bearer YOUR_API_TOKEN
```

OpenClaw uses the same workflow names as Codex:

- `/adsmcp:setup`
- `/adsmcp:performance-review`
- `/adsmcp:write-ad-copy`
- `/adsmcp:wasted-spend`
- `/adsmcp:campaign`

Ad operations go through ADSMCP tools and [Approvals](/approvals). OpenClaw reaches Meta, Google, TikTok, LinkedIn, and Amazon through those tools.

A CLI call usually omits `Origin`. An empty `Origin` is allowed.

## If the call is refused

A missing bearer after the handshake returns HTTP 401, JSON-RPC `-32001`, reason `missing_token`. An unknown token returns `invalid_token`. A token in the query string is `query_token_not_allowed`. An `Origin` from a host outside `claude.ai`, `claude.com`, `cursor.com`, `localhost`, `127.0.0.1`, and the MCP host is HTTP 403, reason `forbidden_origin`. See [MCP protocol](/mcp-protocol).

First request: see the [quickstart](/quickstart).
