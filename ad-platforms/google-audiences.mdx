These tools use the Google Ads connection. See [Google Ads](/ad-platforms/google-ads). Reads that pick an existing audience or conversion action are `search_google_audiences` and `get_google_conversion_actions`.

## Customer Match list

`create_google_customer_match_user_list` creates a Customer Match list (staged for approval like every change). Required arguments are `account_id` and `name`. Optional arguments are `description`, `upload_key_type`, `data_source_type`, and `membership_life_span`.

`upload_key_type` is `CONTACT_INFO`, `CRM_ID`, or `MOBILE_ADVERTISING_ID`. If you omit it, the adapter uses `CONTACT_INFO`. `data_source_type` is `FIRST_PARTY`. If you omit `membership_life_span`, the adapter uses 540. The list is created with membership status `OPEN`.

Every call is staged, whatever `execution_mode` says: the response is `status` `approval_required` with `requested_action`, `queue_id`, `persisted` `true` and `source` `services-mcp-queue`. If the queue cannot store it, the response is `status` `stage_failed` and nothing is staged. A person approves the pending action on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page; only then does ADSMCP call Google. If Google rejects the approved change, the failure is shown on the approval item and is not retried.

## Approved execution

| Tool | Required arguments | What the adapter does |
| --- | --- | --- |
| `create_google_remarketing_user_list` | `account_id`, `name` | Creates an open rule-based list. Omitted lifespan becomes 30. |
| `create_google_conversion_action` | `account_id`, `name` | Creates a webpage conversion action with status `ENABLED`. Omitted category becomes `PURCHASE`. |
| `update_google_conversion_action` | `account_id`, `conversion_action_id` | Updates name, status, goal flag, or value settings. Status is `ENABLED`, `REMOVED`, or `HIDDEN`. An empty update returns no change. |
| `upload_google_customer_match_members` | `account_id`, `user_list_resource_name`, `members` | Adds members that already carry `hashed_email`, `hashed_phone_number`, `mobile_id`, or `third_party_user_id`. |
| `remove_google_user_list_members` | `account_id`, `user_list_resource_name`, `members` | Removes members in that same identifier shape. |
| `attach_google_audience_to_ad_group` | `account_id`, `ad_group_id`, `user_list_resource_name` | Attaches the list with criterion status `ENABLED`. `bid_modifier` is sent only when it is greater than 0. |
| `attach_google_audience_to_campaign` | `account_id`, `campaign_id`, `user_list_resource_name` | Attaches the list. `negative: true` excludes it. |
| `upload_google_click_conversions` | `account_id`, `conversions` | Uploads click conversions. `partial_failure` defaults to true. |
| `upload_google_enhanced_conversions` | `account_id`, `conversions` | Uses the same upload as click conversions. |
| `update_google_campaign_bidding` | `account_id`, `campaign_id`, `strategy_type` | Sets bidding to `MAXIMIZE_CONVERSIONS`, `MAXIMIZE_CONVERSION_VALUE`, `TARGET_ROAS`, or `MANUAL_CPC`. |

Field rules for `update_google_campaign_bidding`, and the bid-strategy read, are on [Google performance and bidding](/ad-platforms/google-performance). `TARGET_ROAS` needs `target_roas` greater than 0. Otherwise the adapter returns no change. A click conversion row is kept only when it has `conversion_action` and `conversion_date_time`. Optional row fields are `gclid`, `gbraid`, `wbraid`, `conversion_value`, `currency_code`, `order_id`, `user_identifiers`, and `consent`.

Member upload does not hash a raw email or phone. A member without one of the identifier fields above is dropped. If every member is dropped, the adapter returns no change.
