Generate a normalized cross-platform performance report. Pass rows to have them added up as given; with no rows it reads your own connected ad accounts on the platforms in scope (up to 5 accounts; Google, Meta, TikTok, LinkedIn, Microsoft Ads, ChatGPT Ads) for date_range (last_7d, last_14d, last_30d, last_90d, this_month, last_month). data_source says which was used; an account that could not be read is listed, never shown as zeros.
