Every client connects to the same server:

```text
https://mcp.adsmcp.si/mcp
```

Per-client steps are on [AI clients](/ai-clients). Sign-in details are on [Authentication](/authentication). Your AI client uses its own model; ADSMCP only supplies the tools.

## OAuth (Claude, ChatGPT, local clients)

Add the URL as a remote MCP server or custom connector and sign in when the browser opens. No key is needed.

- **Claude** (claude.ai, Desktop, Cowork): add a custom connector with the URL.
- **Claude Code:** `claude mcp add --transport http adsmcp https://mcp.adsmcp.si/mcp`, then run `/mcp` and authenticate.
- **ChatGPT:** add a custom connector (developer mode) with the URL and choose OAuth.
- Any client that receives the OAuth callback on `localhost` / `127.0.0.1`.

## API key header (every other client)

Create a key on [API Tokens](https://adsmcp.si/dashboard/api-tokens) and add the server with a header:

```text
Authorization: Bearer sk_live_...
```

Most clients that accept remote MCP servers take a JSON entry like this (the exact key names differ per client; see its page):

```json
{
  "mcpServers": {
    "adsmcp": {
      "url": "https://mcp.adsmcp.si/mcp",
      "headers": { "Authorization": "Bearer sk_live_..." }
    }
  }
}
```

Keep the key in the client's config or an environment variable, never in a prompt.

## STDIO proxy

For clients that only run local (STDIO) MCP servers, run the proxy from a checkout of the ADSMCP repository (after `npm install`). It forwards every call to the remote server and adds your key:

```json
{
  "mcpServers": {
    "adsmcp": {
      "command": "node",
      "args": ["/path/to/ADSMCP/bin/adsmcp-mcp.mjs"],
      "env": { "ADSMCP_API_KEY": "sk_live_..." }
    }
  }
}
```

`ADSMCP_MCP_URL` overrides the server (default `https://mcp.adsmcp.si/mcp`; it must be `https`, except `localhost`). The proxy holds only the API key.

## Agent Pack (skills and slash commands)

The tools work without it. The Agent Pack adds the five workflow commands (`/adsmcp:setup`, `/adsmcp:performance-review`, `/adsmcp:write-ad-copy`, `/adsmcp:wasted-spend`, `/adsmcp:campaign`) and the performance-marketing agent:

- **Claude Code plugin:** from a checkout of the ADSMCP repository, run `/plugin marketplace add /path/to/ADSMCP`, then `/plugin install adsmcp@adsmcp-marketplace`. The plugin also registers the MCP server.
- **Installer:** from the same checkout, `node ./bin/adsmcp-agent.mjs install --client=claude` (or `codex`, `openclaw`, `cursor`, `gemini`). It copies the agent and skill files for that client; add the MCP server itself with one of the methods above.

## Check the connection

Ask the client to call `get_connections_status`. It lists your connected ad platforms. If it fails with `401`, the sign-in or key is wrong; see [Troubleshooting](/troubleshooting).
