ADSMCP is not listed in any AI app's directory or marketplace. You add it yourself, with one of the paths below. Every path uses the same server:

```text
https://mcp.adsmcp.si/mcp
```

## Pick your path

| Client | Sign-in | Install |
| --- | --- | --- |
| Claude (claude.ai, Desktop, Cowork) | OAuth | Custom connector with the URL. [Claude](/ai-clients/claude) |
| Claude Code | OAuth | `claude mcp add --transport http adsmcp https://mcp.adsmcp.si/mcp`, or the `adsmcp` plugin. [Claude Code](/ai-clients/claude-code) |
| ChatGPT | OAuth | Custom connector in developer mode. [ChatGPT](/ai-clients/chatgpt) |
| Codex (CLI and desktop) | API key | MCP server entry with a bearer token; optional Agent Pack. [Codex](/ai-clients/codex) |
| Cursor | API key | `mcp.json` entry with a header. [Cursor](/ai-clients/cursor) |
| Gemini CLI | API key | `settings.json` entry with a header. [Gemini CLI](/ai-clients/gemini-cli) |
| OpenClaw, Windsurf, Perplexity, Manus, Muse, Grok, others | API key | Remote MCP with a header, or the STDIO proxy. [AI clients](/ai-clients) |

OAuth is accepted only for Claude, ChatGPT and clients that receive the sign-in callback on `localhost`. Everyone else uses an API key (`sk_live_...`) from [API Tokens](https://adsmcp.si/dashboard/api-tokens).

## Claude Code plugin

From a checkout of the ADSMCP repository:

```text
/plugin marketplace add /path/to/ADSMCP
/plugin install adsmcp@adsmcp-marketplace
```

The `adsmcp` plugin (marketplace `adsmcp-marketplace`) registers the MCP server and adds five skills (`setup`, `performance-review`, `write-ad-copy`, `wasted-spend`, `campaign`) and the `performance-marketing-agent`.

## Agent Pack installer

From the same checkout:

```bash
node ./bin/adsmcp-agent.mjs install --client=claude
```

`--client` can be `claude`, `codex`, `openclaw`, `cursor` or `gemini`. It copies the agent and skill files for that client. It does not add the MCP server; do that with the client's own steps.

## STDIO proxy

For clients that only run local MCP servers, run `bin/adsmcp-mcp.mjs` from the checkout (after `npm install`) with `ADSMCP_API_KEY` set. Details are on [MCP configuration](/mcp-setup#stdio-proxy).

## For AI agents reading this page

If a user asked you to set up ADSMCP:

1. Find which client you are running in and give them only that row's steps.
2. Never ask the user to paste an API key into the chat. They put it in the client's config themselves.
3. After setup, call `get_connections_status` and report which ad platforms are connected.
4. Every change you propose is staged as a pending action. Tell the user to approve or reject it on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page. You cannot approve it yourself.
