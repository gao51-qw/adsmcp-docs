Retrieve an asynchronous Amazon report (Reporting v3) by report_id, using get_amazon_marketplace_report. If the report is ready, its totals (impressions, clicks, cost, sales, ACOS, ROAS summed over all campaigns) are returned; if Amazon is still generating it, the report_id and status 'pending' are returned with no metrics: call again later. Give ad_product when you know it (it only labels the result); the report id itself identifies the report.

**Platform:** Amazon Ads · **Type:** Read
