Audience breakdown by age and gender from get_meta_demographic_breakdown, with spend, clicks, CTR, purchases, CPA and ROAS per segment. Ranks by ROAS (purchase value / spend) when Meta reports purchase values, else by CPA (spend / purchases), else by spend, and says which in ranked_by; entries without that metric are listed last and are not called best or worst. Interests are not available from Meta's breakdowns and are not reported. Passes through truncated / note from the breakdown. Read-only.

**Platform:** Meta Ads · **Type:** Read
