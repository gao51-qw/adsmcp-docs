**1. Sign Up**

Create your free ADSMCP account at [adsmcp.ai](https://adsmcp.si?utm_source=docs\&utm_medium=page\&utm_content=signup). No credit card required — free tier includes 15 tool calls per month.

**2. Connect Your AI Client**

Pick your AI assistant and follow the setup guide.

> [!NOTE]
>
> **Claude, ChatGPT, Cursor, and Grok Bot:** ADSMCP is an official, reviewed listing in each app's own directory. It's an Anthropic-verified connector in Claude, an OpenAI-reviewed plugin in ChatGPT, and Verified by Cursor in Cursor and Grok Bot. Search for **ADSMCP** and add it. Don't set up a custom connector in Claude, Cursor, or Grok Bot. [All listings and links →](/add-to-your-agent#instructions-for-ai-agents)

**Quick MCP Config Reference**

**Claude Code**

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
/plugin install adsmcp-ads-agent@claude-community
```

Anthropic community marketplace, enabled by default, no setup needed. Bundles the MCP connector with slash commands, skills, and an agent.

**Cursor**

```
/add-plugin adsmcp
```

Or search **adsmcp** in **Customize** and add it. It's Verified by Cursor. Sign-in runs on the first tool call. The same listing works in [Grok Bot](/ai-clients/grok).

**Grok Bot**

No config needed. Open [ADSMCP for Grok Bot](https://x.ai/bot/plugin/66672239) and click **Add to Grok Bot**, or search **adsmcp** in Grok Bot's **Marketplace**. Then click **Authorize** and sign in. ([Step by step](/ai-clients/grok))

**Codex Terminal**

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
codex plugin marketplace add amekala/ads-mcp
```

Then inside Codex run `/plugins` → **ADSMCP** tab → install **ADSMCP Ads Agent**. OAuth runs on first use.

**Codex Desktop**

In the ChatGPT desktop app, switch to **Codex** (top-left dropdown) and send three messages:

```
codex plugin marketplace add amekala/ads-mcp
```

```
install plugin
```

```
help me oauth it
```

Codex runs each one and opens the ADSMCP sign-in. ([Step by step](/ai-clients/codex-desktop))

**OpenClaw**

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
openclaw plugins install openclaw-adsmcp
openclaw adsmcp login
```

**Gemini CLI**

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
gemini extensions install https://github.com/amekala/ads-mcp
```

Browser opens automatically for OAuth on first tool use.

**Windsurf**

Add to `~/.codeium/windsurf/mcp_config.json`:

```json theme={"theme":{"light":"github-light","dark":"github-dark"}}
{
  "mcpServers": {
    "adsmcp": {
      "type": "streamable-http",
      "url": "https://mcp.adsmcp.si/mcp"
    }
  }
}
```

**Perplexity**

In Perplexity Computer, click **Connectors** → **+ Custom connector** and enter:

| Field | Value |
| - | - |
| **Name** | `ADSMCP` |
| **MCP Server URL** | `https://mcp.adsmcp.si/mcp` |

Check the acknowledgment box and click **Add**, then complete OAuth.

**ChatGPT**

Open **Plugins** in ChatGPT, click **Add → Add custom MCP server**, and enter:

| Field | Value |
| - | - |
| **Name** | `ADSMCP-Custom` |
| **Connection** | **Server URL**: `https://mcp.adsmcp.si/mcp` |
| **Authentication** | **OAuth** |

Tick **I understand and want to continue**, click **Create as a plugin**, then **Try in chat → Connect** and click **Authorize** on ADSMCP. Works on every ChatGPT plan, including Free. Use this instead of the ADSMCP plugin, which is having issues right now. ([Step by step, with screenshots](/ai-clients/chatgpt))

**Claude**

No config and no URL. ADSMCP is an Anthropic-verified connector. Open **Customize → Connectors**, search **ADSMCP**, and click **Connect to Claude**.

Want skills and slash commands too? Add the **ADSMCP** plugin from **Customize → Plugins** instead. It includes the same connector. ([Step by step](/ai-clients/claude))

**4. Try It Out**

Once connected, ask your AI assistant:

Verify your ad platform connections are working.

Check my connected ad platforms

You should see a table showing your connected accounts with IDs, names, and connection status.

Then try something real:

Research keywords with real CPC data from Google Keyword Planner.

Research Google Ads keywords for "project management software" — show search volume, CPC, and competition level
