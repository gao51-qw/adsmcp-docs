The published docs host a search MCP at `https://docs.adsmcp.si/mcp`. Coding agents use it to read this site while working on an ADSMCP integration. It searches pages in the docs navigation. It does not call ad platform tools and it cannot approve a spend change.

That server is separate from the product MCP at `https://mcp.adsmcp.si/mcp`.

| Server | URL | Use |
| --- | --- | --- |
| Docs search | `https://docs.adsmcp.si/mcp` | Look up workflows, safety rules, and tool behavior while editing the repo. |
| Product MCP | `https://mcp.adsmcp.si/mcp` | Run ADSMCP tools against a connected ad account. |
| Mintlify admin | `https://mcp.mintlify.com` | Edit Mintlify content after you sign in to the Mintlify account that owns this site. |

## Connect the docs server

Register it under any name; the examples use `adsmcp-docs`.

Claude Code:

```bash
claude mcp add --transport http adsmcp-docs https://docs.adsmcp.si/mcp
```

Codex:

```bash
codex mcp add adsmcp-docs --url https://docs.adsmcp.si/mcp
```

Cursor, or any client that edits `mcp.json` by hand:

```json
{
  "mcpServers": {
    "adsmcp-docs": {
      "url": "https://docs.adsmcp.si/mcp"
    }
  }
}
```

Ask the agent to search the docs before changing a workflow, an approval path, or a platform create tool. The search index updates when Mintlify finishes a deploy of the docs. A page that is not in `docs.json` navigation is excluded unless the site is configured to index every page.

The product OpenAPI reference stays in the API Reference tab. Changes made through the product MCP are never applied on the call: they wait in [Approvals](/approvals) for a person.
