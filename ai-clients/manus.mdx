---
title: "Manus"
description: "Point a Manus agent at the ADSMCP MCP URL. Launches stay paused."
---

The marketing page is [Connect Manus](https://adsmcp.si/manus). In the Manus agent settings, set the MCP server URL to `https://mcp.adsmcp.si/mcp`. Connect ad accounts with OAuth on [Connections](https://adsmcp.si/dashboard/connections).

Manus can coordinate a review, copy, and a report. Campaign creates stay paused. Spend changes wait in [Approvals](/approvals). Ask it to check connected platforms before the first write.

There is no Manus-only tool catalog. The tools are the same ADSMCP catalog.
