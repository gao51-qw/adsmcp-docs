Unlink phone number (call) assets from a campaign. Reads the campaign's asset links (get_google_campaign_asset_links), keeps only CALL links, and unlinks each one with remove_google_asset_link. Pass asset_ids to unlink only those assets; each is checked to be a CALL link on the campaign first and is skipped otherwise. The assets stay in the Asset Library. Reads at most 100 of the campaign's links per call; if that many come back the result is marked truncated and the tool should be run again. Returns one result per link; one failure does not stop the others.

**Platform:** Google Ads · **Type:** Change
