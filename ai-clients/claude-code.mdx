## Setup

### Install

Adding ADSMCP's plugin marketplace once, then installing the plugin, sets up the MCP connector, slash commands, skills, and the Performance Marketing Agent together.

> [!NOTE]
>
> The `/plugin`, `/mcp`, and `/reload-plugins` commands below are **slash commands** — type them directly into the Claude Code input. Do not ask the AI to run them for you (that will cause a "nested session" error).

**1. Add the ADSMCP Marketplace**

ADSMCP runs its own plugin marketplace on GitHub — it's not on a shared/curated marketplace, so you add it once by source.

Type `/plugin` to open the plugin manager. The UI has four tabs — **Discover**, **Installed**, **Marketplaces**, **Errors** — cycle with Tab. Switch to **Marketplaces**, then select **+ Add Marketplace**.

![Claude Code plugin manager Marketplaces tab with + Add Marketplace option](/images/1O0fQlIGCYmUzlC7/images/claude-code/marketplace-tab.png)

Plugin manager — Marketplaces tab, + Add Marketplace

Enter the marketplace source and press Enter:

```
amekala/ads-mcp
```

![Add Marketplace dialog with amekala/ads-mcp entered as the GitHub source](/images/1O0fQlIGCYmUzlC7/images/claude-code/marketplace-add-dialog.png)

Add Marketplace — entering amekala/ads-mcp as the source

This registers ADSMCP's marketplace (`adsmcp-marketplace`) and downloads its plugin list. Or skip the UI and run it directly:

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
/plugin marketplace add amekala/ads-mcp
```

**2. Find and Install the Plugin**

Switch to the **Discover** tab — you'll see **ADSMCP Advertising Agent**.

![Plugin Discover tab showing ADSMCP Advertising Agent plugin](/images/1O0fQlIGCYmUzlC7/images/claude-code/plugin-discover-search.png)

Discover tab — ADSMCP Advertising Agent found after adding the marketplace

Select it and install. Or install directly from the command line:

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
/plugin install adsmcp-advertising-agent@adsmcp-marketplace
```

**3. Reload Plugins**

Claude Code confirms the install and prompts you to reload:

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
/reload-plugins
```

Or close and reopen Claude Code.

![Claude Code output confirming ADSMCP Advertising Agent installed, followed by reload-plugins output](/images/1O0fQlIGCYmUzlC7/images/claude-code/plugin-reloaded.png)

Plugin installed, then /reload-plugins applies it

**4. Authenticate with ADSMCP**

The plugin's MCP server needs a one-time OAuth sign-in. Type `/mcp` to open the MCP server manager.

![Typing the /mcp slash command in Claude Code](/images/1O0fQlIGCYmUzlC7/images/claude-code/mcp-command.png)

Typing /mcp to open the MCP server manager

Find **plugin:adsmcp-advertising-agent:adsmcp** in the list, select it, then choose **Authenticate** — your browser opens for OAuth sign-in.

Sign in with your ADSMCP account and review the requested scopes (campaigns:read/write, performance:read, accounts:read). **New to ADSMCP?** The browser lands on a quick sign-up page first — create a free account (no credit card) and you're sent straight back to the authorization screen. Click **Authorize**.

![ADSMCP OAuth authorization page showing requested scopes](/images/1O0fQlIGCYmUzlC7/images/claude-code/oauth-scopes.png)

OAuth authorization — review and approve the requested scopes

Return to Claude Code and run `/mcp` (or `/plugin`) again — **plugin:adsmcp-advertising-agent:adsmcp** now shows connected with its full tool count. You're ready to go.

![MCP server manager showing plugin:adsmcp-advertising-agent:adsmcp connected](/images/1O0fQlIGCYmUzlC7/images/claude-code/mcp-server-connected.png)

plugin:adsmcp-advertising-agent:adsmcp connected, 20 tools

## Brand Workspace

When you run `/adsmcp:setup`, the agent bootstraps a brand-specific workspace:

1. **Connects to ADSMCP** — verifies your ad platform connections
2. **Scans your folder** — reads any brand docs (`.md`, `.txt`, `.csv`, `.yaml`, `.json`, `.pdf`) for voice, audience, and budget context
3. **Pulls live data** — campaign performance, search terms, benchmarks from all connected platforms
4. **Creates `CLAUDE.md`** — a brand context file with connected platforms, performance snapshot, KPI targets, and brand guidelines

Open your brand folder and run setup:

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
cd ~/Clients/YourBrand
claude
```

Then say "set up my brand workspace" or run `/adsmcp:setup`.

Your brand folder can contain docs or be completely empty — the agent builds context from your live ad platform data either way. More docs = better brand context = better ad copy and recommendations.

## Safety Features

ADSMCP's agent skills enforce safety rules to prevent accidental spend:

* **All campaigns created PAUSED:** You review before they go live
* **User confirmation required:** Claude asks before any action that affects spend
* **Read-before-write:** Skills force research and validation before campaign creation
* **Connection status checks:** Always verifies you're managing the right account first
* **No automatic retries:** If a campaign creation fails, Claude won't retry without asking

## Troubleshooting

### "Nested session" error when installing

If you see `Error: Claude Code cannot be launched inside another Claude Code session`, you're asking the AI to install the plugin instead of typing the slash command yourself. The `/plugin` command must be typed directly into the Claude Code input — don't ask Claude to run them for you.

### Plugin not showing after install

Run `/reload-plugins` after installing, or restart Claude Code. Then verify via either:

* `/plugin` → **Installed** tab — you should see **ADSMCP Advertising Agent** listed
* `/mcp` — you should see **plugin:adsmcp-advertising-agent:adsmcp**

If the plugin is missing from the **Discover** tab, make sure the marketplace was added (`/plugin` → **Marketplaces** tab should list `adsmcp-marketplace`), or refresh it: `/plugin marketplace update adsmcp-marketplace`.

### Authentication keeps failing

Clear your browser cache or try a different browser. The OAuth flow uses PKCE for security — some browser extensions can interfere. Disable ad blockers temporarily.

### MCP server not found

Run `/mcp` and look for **plugin:adsmcp-advertising-agent:adsmcp**. If it's missing, run `/reload-plugins` or restart Claude Code. If it's still missing, re-run:

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
/plugin marketplace add amekala/ads-mcp
/plugin install adsmcp-advertising-agent@adsmcp-marketplace
```

### Tools not working after connecting

Check your ADSMCP account status at [adsmcp.ai](https://adsmcp.si?utm_source=docs\&utm_medium=page\&utm_content=account). Free accounts get 15 tool calls/month. If you've hit the limit, upgrade to Plus ($49/mo for 150 calls) or Pro ($99/mo for 600 calls).

### Skills not loading

Verify the skills directory exists:

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
ls -la ~/.claude/skills/ad-campaign-management/
```

You should see a SKILL.md file. If not, re-run the plugin install command.

### Slash commands not available

If `/adsmcp:setup` isn't recognized, the plugin may not be installed. Run:

```bash theme={"theme":{"light":"github-light","dark":"github-dark"}}
/plugin marketplace add amekala/ads-mcp
/plugin install adsmcp-advertising-agent@adsmcp-marketplace
/reload-plugins
```

## FAQ

> **Do I need to know MCP to use this?**
>
> No. MCP (Model Context Protocol) is the plumbing — you don't interact with it directly. You just talk to Claude in plain English. The MCP connection happens behind the scenes.

> **What's the difference between Claude Code and Claude Cowork / Claude Desktop?**
>
> **Claude Code is Anthropic's terminal/CLI developer tool** — you run `claude` in a shell, it works inside your codebase, optimized for software-engineering workflows. There's also a Claude Code desktop / IDE-side surface.
>
> **[Claude Cowork](/ai-clients/claude-cowork)** is a completely different product — a brand-aware workspace mode inside the Claude desktop app (and on claude.ai). You open a folder, Claude reads its docs, and you collaborate with it on the work in that folder.
>
> Both support ADSMCP through MCP, but they're separate apps. Use Claude Code if you live in the terminal. Use [Claude Cowork](/ai-clients/claude-cowork) if you want a brand-aware workspace with folder context.

> **What does the plugin install?**
>
> The `adsmcp-advertising-agent` plugin installs: the MCP server connection, 5 slash commands (setup, performance-review, write-ad-copy, wasted-spend, refresh-brand-context), a performance marketing agent, and the ad campaign management skill file.

> **Can I manage multiple ad accounts?**
>
> Yes. ADSMCP supports multiple accounts per platform. Use the `switch_primary_account` tool to change which account you're managing, or specify the account ID in your prompts.

> **How much does this cost?**
>
> ADSMCP pricing is based on tool calls, not ad spend. Free tier: 15 calls/month. Plus: $49/mo for 150 calls. Pro: $99/mo for 600 calls. Max: \$199/mo for 3,000 calls. See the [full pricing breakdown](https://adsmcp.si/pricing).

> **Is my data safe?**
>
> Yes. ADSMCP uses OAuth 2.1 with PKCE — we never see your passwords. Your ad account credentials live with Google/Meta/LinkedIn/TikTok. We only get read/write permissions you explicitly authorize. You can revoke access anytime from your ad platform's security settings.
