## Tool order

Klaviyo is not an ad account. The reads change nothing. The one write, `create_klaviyo_campaign`, is staged like every other change: it waits as a pending action until a person approves it on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page.

1. `get_klaviyo_lists`, `get_klaviyo_segments`, `get_klaviyo_metrics`, `get_klaviyo_campaigns`, and `get_klaviyo_flows` are reads. List calls accept `limit`. Campaign reads also accept `channel`.
2. `query_klaviyo_metric_aggregates` requires `metric_id`. Optional `start_date`, `end_date`, and `by` (default `day`). The adapter requests the `count` measurement.
3. `create_klaviyo_campaign` stages a campaign draft. Required arguments are `name` and `list_id`. Optional arguments are `subject`, `from_email`, `from_label`, and `channel` (default `email`). After approval, ADSMCP creates the draft in Klaviyo; it never schedules or sends it. If `name` or `list_id` is missing, nothing is created.

## Connection notes

- Klaviyo appears in the dashboard as an email marketing integration.
- The dashboard does not start OAuth for Klaviyo. The MCP service reads `KLAVIYO_API_KEY`.
- There is no Klaviyo connect button to click. A missing key returns no lists.

## Response fields

A missing `KLAVIYO_API_KEY`, a non-OK Klaviyo response, a metric query without `metric_id`, or a create that lacks `name` or `list_id` returns `ok` false, `error` `adapter_unavailable`, `platform` `klaviyo`, `tool` set to the tool name, `status` `unavailable`, `source` `adapter-unavailable`, and `reason` `adapter-missing`.

| Tool | Body when Klaviyo returns data |
| --- | --- |
| `get_klaviyo_lists` | Array of `id`, `name`, `created`. `limit` defaults to 25. |
| `get_klaviyo_segments` | Array of `id`, `name`, `created`. `limit` defaults to 25. |
| `get_klaviyo_metrics` | Array of `id`, `name`, `integration`. `limit` defaults to 25. |
| `get_klaviyo_campaigns` | Array of `id`, `name`, `status`, `send_time`. `channel` defaults to `email`. `limit` defaults to 25. |
| `get_klaviyo_flows` | Array of `id`, `name`, `status`, `created`. `limit` defaults to 25. |
| `query_klaviyo_metric_aggregates` | The Klaviyo metric-aggregate resource. The request asks for the `count` measurement. `by` defaults to `day`. |
| `create_klaviyo_campaign` | `id`, `name`, `status`. |
