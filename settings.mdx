Open [Settings](https://adsmcp.si/dashboard/settings). The page has four tabs: Profile, Preferences, AI Providers, and Subscription.

## Profile

Full name, email, and user id are read-only. Sign out sends the browser to `/login`.

## Preferences

The tab holds one setting. **Interface language** sets the dashboard language. It applies at once and is saved to your account, so your other devices use it too. There is no separate save button. See [Languages](/knowledge-base/localization).

## Personal AI providers

The AI Providers tab stores a model key for the signed-in user. The provider types are Anthropic (Claude), OpenAI, OpenAI-compatible, Google Gemini, and DeepSeek.

Add a provider with a label, a provider type, a model, and an API key. The request rejects `tenant_id`. A base URL is accepted only for OpenAI-compatible, and it must be a public `https` URL on port 443. The form marks that base URL optional. The agent skips an OpenAI-compatible row that has no base URL.

The key is stored in Vault. A list row reports `has_key` and does not return the key or the Vault name. Rotate key replaces the secret. Delete removes the row. Edit changes the label and model, and the base URL on an OpenAI-compatible row.

**Set default** and **Enable** or **Disable** appear when the row has a model and `has_key` is true. Dashboard features that write text, such as scheduled AI reports, use the row that is both default and active. Without one, generation stops with `ai_provider_required`.

ADSMCP does not supply a model. These are your own provider keys, billed by your provider; MCP and REST tool calls from your AI client do not use them at all.

## Subscription

The tab links to [Usage & Billing](https://adsmcp.si/dashboard/billing) and to [support@adsmcp.si](mailto:support@adsmcp.si). Usage & Billing is where you start the free trial, switch to yearly billing and open **Manage subscription** (card, invoices, cancelling). Limits are on [Pricing](/pricing).
