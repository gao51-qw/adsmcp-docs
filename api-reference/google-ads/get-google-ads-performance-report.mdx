Get Google campaign performance. With lookback_days or start_date/end_date it reads the window live and returns campaigns, ad groups, keywords with quality score, a daily trend (at most 90 points) and impression share; date_range alone keeps the short campaign summary. Read-only; amounts in the account currency.

**Platform:** Google Ads · **Type:** Read

**Also accepted as:** `get_campaign_performance`. These older names run this same tool.
