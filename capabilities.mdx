ADSMCP is an MCP server and dashboard for paid media. It supplies ad-account data, analysis and safe change proposals to the AI client you already use. The AI model is always your own: ADSMCP does not provide or pay for a model. The tools are exposed over MCP and over `POST /api/v1/tools/{name}/execute`; the [API reference](/api-reference/introduction) lists every one.

## Supported now

- **Ad platforms.** Google Ads, Meta Ads, Amazon Ads, TikTok Ads, LinkedIn Ads, ChatGPT Ads and Microsoft Ads. Connect them on [Connections](/connections).
- **Google Ads.** Search, Performance Max, Display, YouTube, Demand Gen, Shopping and App campaign creation (paused), ad groups, responsive search ads, keywords and negatives, assets and extensions, audiences, conversions, and reporting.
- **Meta, Amazon, TikTok, LinkedIn.** Account and performance reads, diagnostics, and the create and update tools listed on each platform page.
- **ChatGPT Ads.** Reads of accounts, campaigns, ad groups, ads, performance, audiences and pixels; paused creates and a one-step ad launch, creative uploads, custom audiences, pixels and conversion setup; pause, resume, archive, and budget or bid changes.
- **Microsoft Ads.** Performance reports (account, campaign, ad group, keyword, search term); reads of accounts, campaigns, ad groups, ads, keywords, budgets, bid strategies, extensions, audiences and targeting; paused Search campaign, ad group, responsive search ad and keyword creates; targeting, budget, bid and status changes.
- **Measurement.** [Google Analytics 4](/marketing-stack/google-analytics) reads, connected with Google sign-in (read-only). [Klaviyo](/marketing-stack/klaviyo) reads lists, segments, metrics, campaigns and flows, and can stage one campaign draft, with your own Klaviyo private API key. [Google Search Console](/marketing-stack/google-search-console) (performance, sitemaps, URL inspection, organic vs paid queries) and [Google Tag Manager](/marketing-stack/google-tag-manager) (accounts, containers, tags, triggers, variables, versions), read-only.
- **Sharing.** [Shared dashboards](/shared-dashboards): no-login, read-only live links for Google Ads, Meta, TikTok, LinkedIn Ads, Microsoft Ads and ChatGPT Ads accounts, with optional white-label.
- **Workflows.** Setup, performance review, ad copy guidelines, wasted spend, and paused campaign creation. See [Workflows](/workflows).
- **Operations.** Pending Actions, the execution queue, a dead-letter queue, monitors, scheduled briefs, automation rules, and the Watch Agent scan.
- **Clients.** Any MCP client that can reach `https://mcp.adsmcp.si/mcp`, with OAuth for Claude, ChatGPT, Cursor, VS Code and local clients, or an API key. Skills and packages for Claude Code, Cursor, Gemini CLI and OpenClaw (installed from source until they are published). See [AI clients](/ai-clients) and [Agent Skills](/agent-skills).
- **Plan and teams.** A Free plan (30 tool calls a month, no card) and ADSMCP Pro with an optional 7-day trial, fair-use limits, active accounts per platform, [teams](/teams), a free month for [referrals](/knowledge-base/referrals), discount codes and the [Prompt Engineering Playbook](/agent-skills/prompt-engineering-playbook). See [Pricing](/pricing).
- **Languages and support.** The website and dashboard in [13 languages](/knowledge-base/localization); [support chat](/support) answered by people.

## How changes work

- **Every change waits for a person.** Creates, pauses, enables, budget, bid and status changes are staged as pending actions. Only a person approves them, on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page. MCP and REST can view or reject, never approve.
- **Creates are paused or drafts.** Nothing starts spending when a create runs.
- **Spend cap.** Budget changes and enables are checked against the account total cap you set; see [Safety model](/safety#spend-cap).
- **Deletes need confirmation.** `remove_*`, `delete_*` and `archive_*` tools (and their `batch_` forms) require `confirm_delete: true`, then approval.
- **No unattended retries.** A change that fails when it runs stops and shows in the execution queue.

## Not supported

- **Snap Ads.** Withdrawn: there are no Snap tools and no Snap connection.
- **Search Console and Tag Manager changes.** Submitting URLs or sitemaps, and creating, changing or publishing tags, are listed as not available; ADSMCP only reads these two products.
- **Amazon Ads on shared dashboards.** Amazon reports are prepared asynchronously and are too slow for a live page.
- **Playbooks for other platforms.** The Prompt Engineering Playbook is for Google Ads accounts only for now.
- **Direct platform calls from the chat client.** Platform APIs are only called inside the MCP service.
- **A default KPI.** Missing targets stop the comparison. The agent does not invent a CPA or ROAS.
- **A built-in AI model.** Copy, summaries and recommendations in prose come from your own AI client.
- **More than 13 interface languages.** Untranslated parts of the dashboard, the legal pages, these docs and tool results are in English.
- **A non-profit discount.** There is none.

Tools that older versions of these docs described but ADSMCP does not have are listed under **Not supported yet** in the [API reference](/api-reference/introduction), each with the tools to use instead.

For how ADSMCP compares with the official Meta, Google and TikTok servers and with other hosted ad MCP products, see [ADSMCP and other ad MCP servers](/knowledge-base/mcp-server-comparison).

## Creative and billing boundaries

The agent can draft copy with your model and stage a paused creative. ADSMCP does not print invoices, change your ad-platform payment method, or replace a designer. Plan changes happen on [Usage & Billing](https://adsmcp.si/dashboard/billing).
