Pause or enable up to 300 keywords in one call (more than 300 is rejected before anything runs). Calls pause_google_keyword or enable_google_keyword once per item, in order, and returns one result per item; a failure on one item does not stop the rest, and isError is set only when every item failed. Reversible, never removes. All keywords must be in the one ad group given.
