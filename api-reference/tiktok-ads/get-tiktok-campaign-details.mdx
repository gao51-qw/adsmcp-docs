Details of one TikTok campaign: its record from get_tiktok_campaigns (name, objective, budget, budget mode, status) and its ad groups from get_tiktok_adgroups (up to 100; truncated is set when there are more). A campaign that is not found, or a failed read, is returned as an error; a failed ad group read is reported in ad_groups_error with the campaign still returned. Read-only.
