Remove a listing group filter (and everything below it, children first) from a Performance Max asset group's tree; its products fall back into the parent's 'everything else' filter. Removing the parent's last specific filter merges the parent back into one unit. The root and 'everything else' filters cannot be removed. Staged for dashboard approval; the approved replay re-reads the target first and refuses if it changed.
