<Update label="November 2026" description="Docs">
  The docs now describe only what ADSMCP does today. The API reference is generated from the ADSMCP code, one page per tool. Pages for tools ADSMCP does not have are marked **Not supported yet** and point to the tools to use instead.
</Update>

<Update label="November 2026" description="Safety">
  - `remove_*` and `delete_*` tools require `confirm_delete: true`, then dashboard approval.
  - New API keys start with `sk_live_`. Existing `pb_` keys keep working.
  - Operator-only governance checks are no longer part of the public tool catalog.
</Update>

<Update label="November 2026" description="Platforms">
  - Google Ads, Meta, LinkedIn and Amazon: additional read and analysis tools.
</Update>

<Update label="October 2026" description="ChatGPT Ads">
  ChatGPT Ads accounts can be connected with an API key. Reads cover accounts, campaigns, ad groups, ads and performance. Pause, resume, budget and bid changes go through approval.
</Update>

<Update label="October 2026" description="Approvals">
  Every ad-platform change is staged for approval, whatever `execution_mode` says. Only a person approves, on the dashboard. Budget changes and enables are checked against an account-total spend cap per platform.
</Update>
