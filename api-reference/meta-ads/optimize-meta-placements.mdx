Rank placements (publisher platform / position, e.g. facebook feed, instagram story, reels) from get_meta_placement_breakdown, to see where spend performs best. Ranks by ROAS (purchase value / spend) when Meta reports purchase values, else by CPA (spend / purchases), else by spend, and says which in ranked_by; entries without that metric are listed last and are not called best or worst. Read-only: it does not move budget or change placements. Passes through truncated / note from the breakdown.

**Platform:** Meta Ads · **Type:** Read
