Every client uses `https://mcp.adsmcp.si/mcp`. Full Agent Pack install, including the five slash commands, is Claude and Codex. Other clients call the same tools and follow the same [workflows](/workflows) in plain language.

Start with the [quickstart](/quickstart) if you have not connected an ad account yet.
