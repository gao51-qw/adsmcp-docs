Upload an image (png, jpg or gif, at most 1024 KiB) to the Amazon creative asset library, for example a brand logo for Sponsored Brands. Send the bytes base64-encoded; no URL is fetched by ADSMCP. Amazon registers it after approval. Staged for dashboard approval; nothing changes in Amazon before a person approves it.

**Platform:** Amazon Ads · **Type:** Change
