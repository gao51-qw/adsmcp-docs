List Amazon campaigns with state and daily budget. ad_product SP, SB or SD lists that product; without ad_product the three lists are merged and every campaign is tagged with its ad_product. limit applies per product. next_token continues a single SB or SD list (Sponsored Products lists return no token). If one product fails the others are still returned and the failure is listed under product_errors; the result is an error only when every requested product fails.
