[Business context](https://adsmcp.si/dashboard/business-context) stores four business numbers for the signed-in tenant:

| Field | How the agent should use it |
| --- | --- |
| Customer lifetime value | Compare a proposed acquisition cost with the value of a customer. |
| Gross margin | Bound a sustainable CPA. Enter the percent. The stored value is the fraction. |
| Sales cycle, in days | Judge whether a conversion window is long enough. |
| CRM qualified leads | See pipeline size. It is a count, not a bid. |

Saving this page does not change an ad account. `STRATEGY.md` remains the source for target ROAS, max CPA, and spend limits. If a KPI required by a workflow is missing there, the workflow still stops. See [Brand and strategy context](/context).
