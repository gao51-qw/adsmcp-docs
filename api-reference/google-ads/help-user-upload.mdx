How images and videos reach ADSMCP's Google tools: they take existing asset ids (or YouTube video ids), never image URLs, so files are uploaded in the Google Ads asset library first. Returns the accepted inputs, the tools that find and validate assets, and Google's image size and ratio rules per asset field. No API call.

**Platform:** Google Ads · **Type:** Read
