## Setup (2 Minutes)

**1. Open Perplexity Computer**

Go to [perplexity.ai](https://www.perplexity.ai) and click **Computer** in the left sidebar. You need a Pro, Max, or Enterprise subscription to access Computer and Connectors.

![Perplexity Computer home page showing Computer sidebar with Connectors option](/images/l_MofcQvSvbf4Ev6/images/perplexity/perplexity-computer.png)

Perplexity Computer — your autonomous AI agent

**2. Open Connectors**

Click **Connectors** in the left sidebar to see all available connectors. Then click **+ Custom connector** in the top-right corner.

![Perplexity Connectors page showing available connectors and Custom connector button](/images/l_MofcQvSvbf4Ev6/images/perplexity/perplexity-connectors.png)

Connectors page — click + Custom connector to add ADSMCP

**3. Add ADSMCP Connector**

In the **Add custom connector** dialog, fill in:

| Field | Value |
| - | - |
| **Name** | `ADSMCP` |
| **Description** | `AI Paid Media Agent` |
| **MCP Server URL** | `https://mcp.adsmcp.si/mcp` |

Check the **"I understand custom connectors can introduce risks"** checkbox, then click **Add**.

![Add custom connector dialog with ADSMCP name, description, and MCP server URL filled in](/images/l_MofcQvSvbf4Ev6/images/perplexity/add-connector-filled.png)

Fill in ADSMCP's MCP server URL and click Add

**4. Authorize ADSMCP**

Perplexity opens ADSMCP's OAuth page. Sign in and authorize access to your ad accounts. You'll see the specific permissions being requested — view campaigns, create ads, view performance metrics, and view connected accounts.

![ADSMCP OAuth authorization page showing requested permissions](/images/l_MofcQvSvbf4Ev6/images/perplexity/oauth-authorize.png)

Authorize ADSMCP to access your ad accounts

**5. Verify Connection**

After authorization, you'll return to the Connectors page. ADSMCP appears with a green checkmark indicating it's connected and ready.

![Perplexity Connectors page showing ADSMCP connected with green checkmark](/images/l_MofcQvSvbf4Ev6/images/perplexity/adsmcp-connected.png)

ADSMCP connected successfully — green checkmark confirms active connection

**6. Add the ADSMCP Skill (Recommended)**

Skills teach Perplexity Computer the *right way* to use ADSMCP's 400+ tools — which tools to call first, how to validate data before creating campaigns, when to ask for confirmation. Without a skill, Computer guesses the tool order. With it, Computer follows proven advertising workflows.

1. Download the SKILL.md file from GitHub:

> **[Download SKILL.md from GitHub](https://github.com/amekala/ads-mcp/raw/main/shared/skills/adsmcp-ads/SKILL.md)**
>
> Click to download the `adsmcp-ads` skill file.

2. In Perplexity Computer, click **Skills** in the left sidebar
3. Click **+ Create skill** in the top-right corner
4. In the **Upload skill** dialog, drag the downloaded `SKILL.md` file or click to upload it

![Perplexity Upload skill dialog showing file requirements and drag-and-drop area](/images/I9hVLERxZr-9OzrZ/images/perplexity/upload-skill-dialog.png)

Upload the SKILL.md file — drag and drop or click to browse

5. The skill appears as **adsmcp-ads** in your Skills list. Perplexity applies it automatically when you ask about advertising.

![Perplexity skill detail showing adsmcp-ads skill with SKILL.md file and description](/images/I9hVLERxZr-9OzrZ/images/perplexity/skill-detail.png)

ADSMCP skill installed — Perplexity applies it automatically when needed

> [!TIP]
>
> The skill file is maintained in the [ads-mcp GitHub repository](https://github.com/amekala/ads-mcp/blob/main/shared/skills/adsmcp-ads/SKILL.md) and always reflects the latest tools and workflows. Check back for updates as new platforms and tools are added.

**7. Start Managing Ads**

Go back to Perplexity Computer and start a new task. ADSMCP's 400+ tools are now available:


You should see a table showing your connected accounts across all platforms with account IDs, names, and connection status.

## FAQ

> **What is Perplexity Computer?**
>
> Perplexity Computer is an autonomous AI agent that can plan, coordinate, and execute complex multi-step tasks. It orchestrates multiple AI models and integrates with 400+ apps. When connected to ADSMCP, it gains direct access to your ad accounts and can run advertising workflows autonomously.

> **Which Perplexity plans support connectors?**
>
> MCP connectors are available on Perplexity Pro ($20/month), Max ($200/month), and Enterprise plans. The free tier does not include connector functionality. Perplexity Computer (for autonomous workflows) requires Max or Enterprise.

> **How is Perplexity different from ChatGPT or Claude for ads?**
>
> All three use the same ADSMCP MCP server, so the 400+ advertising tools are identical. Perplexity's advantage is built-in web search — it can research competitors, market trends, and industry benchmarks in real-time, then immediately act on that research using ADSMCP tools. ChatGPT and Claude don't have native real-time search.

> **Can I use ADSMCP with both Perplexity and other AI clients?**
>
> Yes. Your ADSMCP account works across all platforms. Connect the same MCP URL to Perplexity, ChatGPT, Claude, Cursor, or any MCP-compatible client. Your ad account connections carry across all of them.

> **Does Perplexity support ADSMCP skills?**
>
> Yes. Perplexity Computer supports skills — upload a `SKILL.md` file via **Computer → Skills → + Create skill**. The `adsmcp-ads` skill teaches Computer proven advertising workflows and is available in the [ads-mcp GitHub repo](https://github.com/amekala/ads-mcp/blob/main/shared/skills/adsmcp-ads/SKILL.md). Perplexity applies skills automatically when relevant to your prompt.

> **How much does this cost?**
>
> ADSMCP pricing is based on tool calls, not ad spend. Free tier: 15 calls/month. Plus: $49/mo for 150 calls. Pro: $99/mo for 600 calls. Max: \$199/mo for 3,000 calls. See [full pricing](https://adsmcp.si/pricing). Perplexity's subscription is separate.

> **Why does the connector dialog say 'can introduce risks'?**
>
> This is a standard Perplexity warning for all custom (third-party) connectors. ADSMCP uses OAuth 2.1 with PKCE — the same security standard used by banking apps. Your ad platform credentials are never shared with Perplexity. See [Security](/knowledge-base/security) for details.
