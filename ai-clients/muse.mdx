---
title: "Muse"
description: "Add ADSMCP to Muse as a custom MCP connector."
---

Add a custom MCP connector with URL `https://mcp.adsmcp.si/mcp`. If Muse asks for a header, use `Authorization: Bearer YOUR_API_TOKEN` from [API Keys](https://adsmcp.si/dashboard/api-tokens).

Muse can review performance, look up account data, and draft a paused campaign. It does not get a separate plugin. Spend-affecting changes wait in [Approvals](/approvals).

First request: see the [quickstart](/quickstart).
