These tools use the Meta connection. See [Meta Ads](/ad-platforms/meta-ads). Every write is staged as a pending action and runs only after a person approves it on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page, whichever `execution_mode` you pass. When the queue is unavailable, the call returns `approval_queue_required` and does not post to Meta.

## Reads

The three breakdown tools read Meta insights split by the fields below and return `rows`.

`get_meta_experiments` is not connected yet: it returns `status` `unavailable`, `source` `adapter-unavailable`, `reason` `unsupported-capability`, and an empty `experiments` array.

| Tool | Breakdowns |
| --- | --- |
| `get_meta_creative_breakdown` | `image_asset`, `video_asset`, `title_asset`, `body_asset` |
| `get_meta_placement_breakdown` | `publisher_platform`, `platform_position` |
| `get_meta_demographic_breakdown` | `age`, `gender` |

## A/B plan

`create_meta_ab_test_plan` requires `account_id`, `name`, `variants`, and `success_metric`. `hypothesis` is optional. `execution_mode` is `paused` or `approval_required`. The queued arguments wait in [Approvals](/approvals). An approved execution posts `name`, `variants`, and `success_metric` to that account's experiments edge.

## Copies and ad set status

| Tool | Required argument | Queued change |
| --- | --- | --- |
| `pause_ad_set` | `ad_set_id` | Status `PAUSED`. |
| `enable_ad_set` | `ad_set_id` | Status `ACTIVE`. |
| `copy_campaign` | `campaign_id` | Copy request. |
| `copy_ad_set` | `ad_set_id` | Copy request. |
| `copy_ad` | `ad_id` | Copy request. |

`deep_copy` on a campaign or ad set copy must be a boolean when you set it. The approved post sends `deep_copy` true. `copy_ad` has no `deep_copy` argument. The approved ad copy post still sends `deep_copy` true. The approved copy post does not send a status field.

## Read result

The experiment and breakdown reads use the unavailable body in the Reads section.

## Write result

A missing required id, a non-boolean `deep_copy`, or an `execution_mode` outside `paused` and `approval_required` is JSON-RPC HTTP 400, code `-32602`, `reason` `invalid_arguments`.

A stored write is `status` `staged`, with `queue_item` and `source` `services-mcp-queue`. The A/B plan also returns `account_id`, `experiment_status`, and `execution_mode`. The queue stores the arguments you sent. The approved post sends `name`, `variants`, and `success_metric`.

The queue stores the arguments you sent. The approved copy post sends only `deep_copy` true.
