Every ADSMCP tool is callable over MCP and as `POST /api/v1/tools/{name}/execute`. The [API reference](/api-reference/introduction) has one page per tool, generated from the ADSMCP code, with its exact arguments. The machine-readable list is `GET https://mcp.adsmcp.si/api/v1/tools`.

Tools fall into three kinds:

- **Reads** return data or computed analysis and change nothing.
- **Changes** would change an ad account. They are never applied on the call: each one becomes a pending action that a person approves on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page.
- **Controls** manage ADSMCP's own records: monitors, schedules, automation rules, and views of the approval queue.

## When to use which tool

Call `get_connections_status` before anything else.

| Job | Start with | What happens to changes |
| --- | --- | --- |
| See what is connected | `get_connections_status`, `list_connected_accounts` | No change. |
| Check the plan | `get_usage_status` | No change. |
| Refresh local brand files | `sync_brand_context`, `sync_strategy_context` | Rewrites context files only, after you agree. |
| Score the account | Platform read tools, then `generate_cross_platform_report` | Recommendations wait until you pick one. |
| Find waste | `analyze_wasted_spend` and the platform wasted-spend reads | Pauses and budget changes become pending actions. |
| Build a Google Search campaign | `validate_google_search_campaign_draft`, then `create_search_campaign` | Staged; created paused once approved. |
| Build another Google type | `create_google_pmax_campaign`, `create_google_display_campaign`, `create_google_youtube_campaign`, `create_google_demand_gen_campaign`, `create_google_shopping_campaign`, `create_google_app_campaign` | Same. |
| Build on Meta, Amazon, TikTok or LinkedIn | The platform's create tool (see its platform page) | Same. |
| Pause, enable, change budget or bid | The platform's pause, enable or update tool | Staged; enables and budget changes are checked against the [spend cap](/safety#spend-cap). |
| Delete or remove | A `remove_*` / `delete_*` tool with `confirm_delete: true` | Staged; irreversible once approved. |
| See the queue | `list_pending_actions`, `list_execution_queue`, `list_dead_letter_queue`, `get_action_audit` | View only. `manage_action` can reject. |

A tool result is JSON text. Read it for `ok: false`, `blocked` or `unavailable` even when the call itself succeeded.
