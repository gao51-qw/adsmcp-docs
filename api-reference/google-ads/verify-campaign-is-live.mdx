Check that a campaign exists and is live. GOOGLE ADS ONLY (verify_google_campaign_is_live): any other platform returns an explicit 'unsupported' error, because there is no live-check tool for Meta, TikTok, LinkedIn or Amazon. 'Live' here means the campaign status is ENABLED; budget and serving status are not checked. A campaign that is not found and missing Google credentials are indistinguishable in the underlying tool and are both returned as an error.

**Platform:** Google Ads · **Type:** Read
