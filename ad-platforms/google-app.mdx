App campaigns use the Google Ads connection. See [Google Ads](/ad-platforms/google-ads).

## Order

1. `get_connections_status` and `get_google_ads_accounts`.
2. `create_google_app_campaign` creates a paused shell.
3. `enable_google_campaign` is a separate approved action. See [Approvals](/approvals).

This call does not create an asset group or a store-listing experiment.

## Required fields

| Field | Rule |
| --- | --- |
| `account_id` | Google Ads customer id. |
| `name` | Non-empty campaign name. |
| `budget_micros` | Positive integer. |
| `app_id` | Store app id, trimmed. An empty value throws `app_id is required`. |
| `app_store` | `GOOGLE_APP_STORE` or `APPLE_APP_STORE`. Any other value throws. |

Optional fields:

| Field | Rule |
| --- | --- |
| `target_cpa_micros` | Positive integer. Present: goal type `OPTIMIZE_INSTALLS_TARGET_INSTALL_COST` and a target CPA. Absent: goal type `OPTIMIZE_INSTALLS_WITHOUT_TARGET_INSTALL_COST`. |
| `execution_mode` | `approval_required` stages the create and does not call Google on that request. |
| `validate_only` | Forwarded on the Google mutate. |
| `login_customer_id` | Manager account id when Google requires one. |

The campaign status is `PAUSED`. The channel is `MULTI_CHANNEL` with subtype `APP_CAMPAIGN`.

## What the call returns

`execution_mode: "approval_required"` returns `status: "approval_required"`. A successful queue insert sets `persisted: true` and `queue_id`. The row status is `pending_approval`.

A direct call without `GOOGLE_DEVELOPER_TOKEN` returns `status: "blocked"`, `reason: "google_adapter_unavailable"`. A successful adapter result returns `status: "created_paused"` with `campaign_resource_name` and `budget_resource_name`. A result without a campaign resource name or campaign id returns `status: "blocked"`, `reason: "no_connection"`.

`isError` stays false. Read the JSON text. See [MCP protocol](/mcp-protocol).
