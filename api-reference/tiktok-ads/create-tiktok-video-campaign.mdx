Launch a TikTok In-Feed video campaign, created disabled: validate_tiktok_campaign_draft (pre-flight, read-only) -\> create_tiktok_campaign (daily budget, campaign budget optimization) -\> create_tiktok_adgroup (targeting, lowest-cost bidding) -\> create_tiktok_ad (the video), each step using the id the previous one returned. Objectives: TRAFFIC, VIDEO_VIEWS, REACH. The video must already be in the ad library (video_id); the tool does not upload from a URL (use upload_tiktok_video), so video_url and its dimensions are only used for the pre-flight check. execution_mode approval_required (default) queues each step for approval and stops at the first queued step, returning the remaining steps: after it is approved and executed, run the next step with the id from the executed result (campaign_id or adgroup_id, in the queue execution response under result.payload) in place of each \{"$fromStep": n\} reference. execution_mode paused is queued the same way: no TikTok write runs before it is approved. This tool launches an In-Feed video campaign with a daily budget (objective TRAFFIC, VIDEO_VIEWS or REACH) from a video that is already in the ad library. It cannot upload a video from a URL (use upload_tiktok_video first), boost an organic post (use create_tiktok_spark_ad), build a carousel (use create_tiktok_carousel_ad), set lifetime budgets, or run conversion, lead and app objectives; build those with create_tiktok_campaign, create_tiktok_adgroup and create_tiktok_ad.

**Platform:** TikTok Ads · **Type:** Change
