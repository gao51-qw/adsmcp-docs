The server is `https://mcp.adsmcp.si/mcp`. It speaks MCP over Streamable HTTP: one JSON-RPC 2.0 message per `POST`. Sign-in is on [Authentication](/authentication).

## Protocol versions

`/mcp` accepts protocol versions `2026-07-28`, `2025-11-25`, `2025-06-18` and `2025-03-26`. The older per-platform endpoints (`/api/mcp/<platform>`) accept the three 2025 versions.

## Authentication

Every request needs either an OAuth access token or an API key in `Authorization: Bearer ...`. A token in the query string is rejected. A `401` carries `WWW-Authenticate` pointing at the protected-resource metadata:

- `https://mcp.adsmcp.si/.well-known/oauth-protected-resource` (also under `/mcp`) names the resource and its authorization server.
- The authorization server supports the authorization-code and refresh-token grants with PKCE `S256` and dynamic client registration.

## Tool surfaces

| Endpoint | What `tools/list` shows |
| --- | --- |
| `/mcp` | A compact router surface: one `<platform>_read` and one `<platform>_write` tool per platform (for example `google_ads_read`, `meta_ads_write`), plus `search_tools` and `get_tool_schema`. Every catalog tool can also be called directly by name. |
| `/mcp/flat` | Every public tool by its own name, with its full input schema. |

A router call looks like this:

```json
{
  "name": "google_ads_read",
  "arguments": {
    "action": "execute",
    "tool_name": "get_google_ads_campaigns",
    "arguments": { "account_id": "1234567890" }
  }
}
```

`action: "list_tools"` lists the tools behind a router. `search_tools` takes a `query` (English or Chinese, or a tool name) and an optional `platform`; `get_tool_schema` takes a tool name and returns its arguments.

Tools carry `readOnlyHint` for reads and `destructiveHint` for changes. Operator-only governance checks are not on either surface.

## Results

A tool result is MCP `content` with a JSON text block. Read the JSON: a result can be `ok: false`, `blocked` or `unavailable` even when the MCP call itself succeeded. A change returns its pending action, not a finished change; see [Approvals](/approvals).
