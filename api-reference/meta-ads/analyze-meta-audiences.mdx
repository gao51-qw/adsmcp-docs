Which age / gender segments perform best, from get_meta_demographic_breakdown. Ranks by ROAS (purchase value / spend) when Meta reports purchase values, else by CPA (spend / purchases), else by spend, and says which in ranked_by; entries without that metric are listed last and are not called best or worst. Meta's untargetable Unknown age or gender bucket stays in the ranking but is never called best or worst. Interests are not available from Meta's breakdowns and are not reported. Passes through the breakdown's truncated / note when its row cap was hit. Read-only.
