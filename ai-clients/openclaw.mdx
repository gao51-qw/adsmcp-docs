OpenClaw connects to ADSMCP with an API key. Create one on [API Tokens](https://adsmcp.si/dashboard/api-tokens) first (it starts with `sk_live_`) and keep it in the `ADSMCP_API_KEY` environment variable, never in a chat message.

## Add the server

```bash
openclaw mcp set adsmcp '{"url":"https://mcp.adsmcp.si/mcp","transport":"streamable-http","headers":{"Authorization":"Bearer ${ADSMCP_API_KEY}"}}'
```

The header holds a reference to the environment variable, resolved when OpenClaw connects, not the key itself. If the client can only start local (STDIO) servers, use the [STDIO proxy](/mcp-setup#stdio-proxy) instead.

## The `openclaw-adsmcp` package

The package adds 14 [skills](/agent-skills) and an `openclaw adsmcp` command group. It is not on npm or ClawHub yet (coming soon). From a checkout of the ADSMCP repository:

```bash
npm pack ./plugins/openclaw/openclaw-adsmcp --pack-destination /tmp
openclaw plugins install npm-pack:/tmp/openclaw-adsmcp-1.1.0.tgz
export ADSMCP_API_KEY=sk_live_...
openclaw adsmcp login
openclaw gateway restart
```

| Command | Does |
| --- | --- |
| `openclaw adsmcp login` | Saves the `adsmcp` server with `Authorization: Bearer ${ADSMCP_API_KEY}`. Without the variable it prints where to create a key and stops. `--token <key>` writes the key into OpenClaw's own config instead (the variable is recommended). |
| `openclaw adsmcp logout` | Removes the server (`openclaw mcp unset adsmcp`). |
| `openclaw adsmcp status` | Server status and the number of installed skills. |
| `openclaw adsmcp tools` | Lists the ADSMCP tools. |
| `openclaw adsmcp accounts` | Calls `get_connections_status` with `ADSMCP_API_KEY`. |
| `openclaw adsmcp connect` | Opens [Connections](https://adsmcp.si/dashboard/connections). |

The Agent Pack installer (`node ./bin/adsmcp-agent.mjs install --client=openclaw`) is an alternative for the agent and skills only. See [Agent Skills](/agent-skills).

## After you connect

1. Ask your first question, for example: *"Which campaigns spent money last week without a single conversion?"*
2. If you have not connected an ad account yet, the reply contains a link to [Connections](https://adsmcp.si/dashboard/connections). Connect the platform there and ask again.
3. Ask for a read, such as last week's performance, before asking for changes.

Every change the client proposes is staged as a pending action. Approve or reject it on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page, or in the client's confirm dialog if it is an [allowed AI client](/approvals#approving-in-your-ai-client); the AI model itself cannot approve it. The client runs on your own AI model and plan, and each ADSMCP tool call counts against your [ADSMCP plan](/pricing).
