The marketing page is [Connect Windsurf](https://adsmcp.si/windsurf). The server is the same remote endpoint as every other client.

Add this entry to `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "adsmcp": {
      "type": "streamable-http",
      "url": "https://mcp.adsmcp.si/mcp"
    }
  }
}
```

Restart Windsurf and complete OAuth. If the client asks for a header instead, set `Authorization: Bearer YOUR_API_TOKEN` from [API Keys](https://adsmcp.si/dashboard/api-tokens). Connect at least one ad account on [Connections](https://adsmcp.si/dashboard/connections) before asking for a platform report.

Windsurf does not install the five slash commands. First prompt: "Check my connected ad platforms." Leave spend unchanged in that prompt. Workflow order is [Workflows](/workflows).

## If the call is refused

Allowed browser origins are `claude.ai`, `claude.com`, `cursor.com`, `localhost`, `127.0.0.1`, their subdomains, and the MCP host. A Windsurf page origin outside that list returns HTTP 403, JSON-RPC `-32001`, reason `forbidden_origin`. Omitting `Origin` passes the check.

A missing bearer after the handshake is HTTP 401, reason `missing_token`. See [MCP protocol](/mcp-protocol). Spend waits in [Approvals](/approvals).
