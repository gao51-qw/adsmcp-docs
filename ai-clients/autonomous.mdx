title: "Autonomous agents"
description: "Agents that run unattended (Manus, Codex, Cowork tasks, scheduled scripts) use the same server and the same approval queue."
---

Agents that work through a task on their own connect like any other client: Claude Cowork with OAuth, everything else with an API key. See [AI clients](/ai-clients).

What changes when nobody is watching:

- **They cannot approve.** An agent can read, analyze and stage changes. Every change waits for a person on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page. `approve`, `execute_queued_action` and `retry_queued_action` are refused with `approval_requires_dashboard`.
- **They share your quota.** All clients on your ADSMCP account draw from the same monthly tool calls ([Pricing](/pricing)). Name the account ids so a run does not scan every connected account.
- **Failures stop.** A failed change is not retried by ADSMCP.

First prompt for an unattended run: *"Call get_connections_status. Report what is connected. Do not stage any change unless I asked for it in this task."*

## After you connect

1. Ask: *"Call get_connections_status and tell me which ad platforms are connected. Do not change anything."*
2. If a platform is missing, connect it on [Connections](https://adsmcp.si/dashboard/connections).
3. Ask for a read, such as last week's performance, before asking for changes.

Every change the client proposes is staged as a pending action. Approve or reject it on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page; the client cannot approve it. The client runs on your own AI model and plan, and each ADSMCP tool call counts against your [ADSMCP plan](/pricing).
