ADSMCP is an approval-first MCP server and dashboard for paid media. The catalog is exposed over MCP and over `POST /api/v1/tools/{name}/execute`.

## Supported now

- **Ad accounts.** Meta, Google Ads, TikTok, LinkedIn, and Amazon. Connect them on [Connections](/connections).
- **Google Ads work.** Search, Performance Max, Display, YouTube, Demand Gen, Shopping, and a paused App campaign shell. Search creation validates, then creates a paused shell.
- **Meta, TikTok, LinkedIn, Amazon.** Diagnostics, plus the create and update paths on each platform page. Amazon reports take `ad_product` as `sp`, `sb`, or `sd`.
- **Measurement.** Google Analytics 4 is read-only. Klaviyo reads lists, segments, campaigns, and flows, and can create one campaign draft.
- **Workflows.** Setup, performance review, ad copy, wasted spend, and paused campaign creation. See [Workflows](/workflows).
- **Operations.** Pending Actions, an execution queue, payload checks, a dead-letter queue, scheduled briefs, automation rules, and an admin Watch Agent.
- **Clients.** Any client that can call the remote MCP URL. Full Agent Pack install is Claude and Codex. See [AI clients](/ai-clients).

## Not supported

- **ChatGPT Ads.** No tools are registered for ads inside ChatGPT. ChatGPT the app can still be a client that calls ADSMCP.
- **Snap Ads.** New connections and catalog tools are removed. Older stored rows are left in place. A Snap call returns withdrawn rather than a live account.
- **Spend from every create.** Google, Meta, and TikTok campaign creates stay paused or disabled. LinkedIn campaign groups and creatives are created active. Amazon pause, enable, and budget changes run on the request. An approved `update_tiktok_campaign` changes the live name or budget. The platform page names the path.
- **Unattended retries.** A failed spend-affecting write stops.
- **Direct platform calls from the chat client.** Those hosts are only called inside the MCP service.
- **A default KPI.** Missing targets stop the comparison. The agent does not invent a CPA or ROAS.
- **Translated product UI.** The interface stays English.
- **A one-click listing inside ChatGPT, Claude, or Cursor.** Add the server URL or install the Agent Pack. There is no separate marketplace install step in this product.

## Creative and billing boundaries

The agent can draft copy and queue a paused creative. It does not print invoices, change your ad-platform payment method, or replace a designer. Plan changes happen on [Usage & Billing](https://adsmcp.si/dashboard/billing).
