Lead ads use the Meta connection. The OAuth grant includes `leads_retrieval` and `pages_manage_ads`. See [Meta Ads](/ad-platforms/meta-ads).

## Order

1. `get_connections_status`, then `get_ad_accounts`.
2. `get_pages` lists Facebook pages the connected user can manage. It does not take an ad account id.
3. `get_lead_forms`, `get_meta_lead_form_questions`, `get_lead_form_leads`, and `get_meta_lead_quality_report` each return `status` `unavailable`, `source` `adapter-unavailable`, and `reason` `unsupported-capability`, with an empty `lead_forms`, `questions`, or `leads` array. They do not return forms, questions, submissions, or a quality score. `get_pages` still reads `me/accounts`.

## Create a form

`create_meta_lead_form` is a write. Required arguments are `page_id`, `name`, a non-empty `questions` array, and a `privacy_policy` object. Optional arguments are `locale`, `follow_up_action_url`, and `thank_you_page`.

`execution_mode` is `paused` or `approval_required`. If you omit it, the write is treated as `paused`. Any other value is rejected. The call waits in [Approvals](/approvals). If the approval queue is not available, the call returns `approval_queue_required` and does not create the form. Approving the queued form returns `result` with `ok` false and `reason` `unsupported_meta_write`. `questions` and `privacy_policy` are not posted to the Page lead-form edge.

A campaign that should use the form is still `create_campaign`, `create_ad_set`, and `create_ad`, each left `PAUSED`. Enabling spend is `enable_campaign` and is a separate approval.

## Result fields

A missing `page_id`, `name`, `questions`, or `privacy_policy`, or an `execution_mode` outside `paused` and `approval_required`, is JSON-RPC HTTP 400, code `-32602`, `reason` `invalid_arguments`.

A stored form is `status` `staged`, with `page_id`, `execution_mode`, `queue_item`, and `source` `services-mcp-queue`. The stored body keeps `name`, `questions`, `privacy_policy`, and any `locale`, `follow_up_action_url`, or `thank_you_page` you set. An approved execution returns `page_id`, `execution_mode`, `approved_action_id`, `result`, and `source` `services-mcp-local`.
