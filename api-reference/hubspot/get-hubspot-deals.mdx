HubSpot CRM deals closed in a period, from the user's own HubSpot portal: closed-won deals by default (status all: every deal whose close date is in the period, open deals by their expected close date). Each deal has its amount, currency (the deal's, else the portal's), close date, pipeline and stage ids, and the original traffic source HubSpot recorded for its contact (hs_analytics_source, hs_analytics_source_data_1, hs_analytics_source_data_2; the first associated contact that has one, else the deal's own), UTM values where the portal stores them, the ad platform that source maps to (as in analyze_hubspot_revenue_by_ad_source) and matched_by, the signal that decided it (click_id, utm_source, referrer, drill_down). Up to 1,000 deals (limit), oldest close date first; truncated: true when HubSpot holds more. Read-only.

**Platform:** HubSpot · **Type:** Read
