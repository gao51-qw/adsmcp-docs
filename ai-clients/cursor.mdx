ADSMCP is not in the Cursor Marketplace yet. Add the server yourself; Cursor can sign in with OAuth.

## Add the server (OAuth)

Add this to `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` in a project:

```json
{
  "mcpServers": {
    "adsmcp": {
      "url": "https://mcp.adsmcp.si/mcp"
    }
  }
}
```

Reload Cursor and sign in to `adsmcp` when its MCP settings ask for it. A browser opens: sign in to ADSMCP, review what Cursor will be able to do, and choose **Allow**. ADSMCP accepts Cursor's sign-in for the desktop app (`localhost` callback) and for Cursor on the web and Cursor Agents (Cursor's published callback).

## Or use an API key

Create a key on [API Tokens](https://adsmcp.si/dashboard/api-tokens) (it starts with `sk_live_`) and send it as a header. Keep it in an environment variable, never in a chat message:

```json
{
  "mcpServers": {
    "adsmcp": {
      "url": "https://mcp.adsmcp.si/mcp",
      "headers": { "Authorization": "Bearer ${env:ADSMCP_API_KEY}" }
    }
  }
}
```

If the client can only start local (STDIO) servers, use the [STDIO proxy](/mcp-setup#stdio-proxy) instead.

## Skills and the ADSMCP plugin

- **Skills now:** the [Agent Skills](/agent-skills) installer copies ADSMCP's skills to `~/.agents/skills`, which Cursor reads. Force one with `/adsmcp-<name>`, or ask in plain language.
- **Cursor plugin (coming soon):** a plugin with the MCP server, the `performance-marketing-agent`, 14 skills and two rules (`use-adsmcp`, `brand-workspace`) is prepared but not yet in the Cursor Marketplace. It authenticates with an API key you give it as the `ADSMCP_API_KEY` variable.

## After you connect

1. Ask: *"Call get_connections_status and tell me which ad platforms are connected. Do not change anything."*
2. If a platform is missing, connect it on [Connections](https://adsmcp.si/dashboard/connections).
3. Ask for a read, such as last week's performance, before asking for changes.

Every change the client proposes is staged as a pending action. Approve or reject it on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page; the client cannot approve it. The client runs on your own AI model and plan, and each ADSMCP tool call counts against your [ADSMCP plan](/pricing).
