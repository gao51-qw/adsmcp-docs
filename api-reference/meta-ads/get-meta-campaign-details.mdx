Campaign details for a Meta ad account from get_campaigns: objective, status, daily / lifetime budget and budget_remaining as Meta returns them (the account currency's minor units; the currency code is not part of the result). With campaign_id, returns that campaign only plus its ad sets from get_ad_sets, which carry the bid strategy and any ad-set budgets. Reads the first 100 campaigns of the account. Read-only.

**Platform:** Meta Ads · **Type:** Read
