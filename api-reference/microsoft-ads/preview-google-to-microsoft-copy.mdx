Preview copying a Google Ads Search campaign into a Microsoft Ads account: reads the Google campaign (settings, daily budget, bidding, ad groups, keywords with match types and bids, negative keywords of the campaign, its ad groups and its shared lists, responsive search ads, location targets, sitelinks and callouts) and returns the Microsoft Ads plan copy_google_campaign_to_microsoft would create, with counts and not_copied naming every item that cannot be carried over and why. Only Search campaigns (others: campaign_type_not_supported); both accounts must use the same currency (else currency_mismatch). Location targets need location_map (Google and Microsoft number locations differently). Makes no Microsoft Ads call and changes nothing.

**Platform:** Microsoft Ads · **Type:** Read
