Empower your AI assistants with high-level advertising strategy and operational skills.

## What are Agent Skills?

Skills are the workflow instructions behind the five commands in [Workflows](/workflows). A single tool performs one operation. A skill tells the agent which tools to call, in which order, and when to stop for approval.

ADSMCP workflows start by checking `get_connections_status`, create campaigns only in paused or approval-required modes, and do not auto-retry failed spend-affecting writes.

<Card title="Setup" icon="wrench">
  Command: `/adsmcp:setup`. Checks `CLAUDE.md`, `STRATEGY.md`, and `MEMORY.md`, calls `get_connections_status`, and reports which platforms are connected and which command to run next. It does not invent a default CPA, ROAS, CTR, or budget.
</Card>

<Card title="Performance review" icon="chart-line">
  Command: `/adsmcp:performance-review`. Returns a scorecard and the top three recommendations. A write becomes a Pending Action only after you pick one.
</Card>

<Card title="Write ad copy" icon="pen">
  Command: `/adsmcp:write-ad-copy`. Calls `generate_ad_copy_ideas` for tone, banned terms, and KPI targets, then writes the variants in the chat. The tool does not return headlines. Turning a variant into an ad queues a Pending Action and leaves the ad paused. Search ad counts are on [Google keywords and assets](/ad-platforms/google-search).
</Card>

<Card title="Wasted spend" icon="filter">
  Command: `/adsmcp:wasted-spend`. Returns findings ranked by dollar impact. Pauses, exclusions, and budget changes are Pending Actions.
</Card>

<Card title="Campaign" icon="magnifying-glass">
  Command: `/adsmcp:campaign`. Returns a paused campaign, or an approval-required draft. Google Search uses `validate_google_search_campaign_draft`, then `create_search_campaign`. Enabling spend is a separate approval.
</Card>

The tool order for each command is on [Workflows](/workflows). Claude and Codex use the `/adsmcp:*` names above. Gemini CLI uses `/skill adsmcp:setup`, `/skill adsmcp:performance-review`, `/skill adsmcp:write-ad-copy`, `/skill adsmcp:wasted-spend`, and `/skill adsmcp:campaign`. Cursor maps `@adsmcp setup`, `@adsmcp review`, `@adsmcp copy`, `@adsmcp audit`, and `@adsmcp campaign` onto the same five commands.

## The brand workspace

Skills rely on local project files to persist context. Keeping these files in your repository keeps the agent aligned with the brand.

- `AGENTS.md` defines the persona, tone, and guardrails for the advertising agent.
- `STRATEGY.md` stores global KPIs, target CPA, and preferred scaling strategies.
