Codex Desktop and the Codex CLI both use `https://mcp.adsmcp.si/mcp`. This page is the desktop app. CLI install and the five slash commands stay on [Codex](/ai-clients/codex).

## Connect

Add the remote URL in Codex Desktop. There is no second plugin. If the app asks for a header, use `Authorization: Bearer YOUR_API_TOKEN` from [API Keys](https://adsmcp.si/dashboard/api-tokens).

Ask for the workflow by name: setup, performance review, ad copy, wasted spend, or campaign. The tool order matches [Workflows](/workflows).

Spend changes wait in [Approvals](/approvals). First request: see the [quickstart](/quickstart).
