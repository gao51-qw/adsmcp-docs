Create a YouTube video campaign: a Demand Gen campaign running on YouTube in-feed, in-stream and Shorts only (Gmail, Discover and Display off), with its budget, ad group and a video responsive ad built from your YouTube videos, headlines, descriptions, business name, an existing square logo asset and a call to action. Everything is created PAUSED; enable it with enable_google_campaign (account-total spend cap). Run validate_video first. contains_eu_political_advertising is your own declaration to Google. Staged for dashboard approval; the approved replay re-reads the target first and refuses if it changed.

**Platform:** Google Ads · **Type:** Change
