Upload up to 20 images to the TikTok asset library from public https URLs: one upload_tiktok_image (upload_type UPLOAD_BY_URL; TikTok downloads the image itself, ADSMCP fetches nothing) per URL, each queued for approval as its own row. Nothing is uploaded until a person approves a row on the dashboard; each approved row returns its TikTok image_id. TikTok enforces its own size and format limits.

**Platform:** TikTok Ads · **Type:** Change
