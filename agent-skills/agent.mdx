The `performance-marketing-agent` is an agent definition that ships with the `adsmcp` Claude Code plugin and the Agent Pack installer. It runs on your AI client's own model. It does not add tools: it tells the model how to use the ADSMCP tools safely and in the right order.

## What it does on every task

1. Loads `CLAUDE.md` (brand voice and rules), `STRATEGY.md` (KPI targets and budget limits) and `MEMORY.md` (past decisions).
2. Calls `get_connections_status` before any platform tool.
3. Picks the matching workflow skill: setup, performance review, ad copy, wasted spend, or campaign.
4. Runs read-only analysis first.
5. Stages any change as a pending action and tells you to approve or reject it on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page. It cannot approve anything itself.
6. Records confirmed outcomes with `record_learning`.

If context is missing, it sends you to `/adsmcp:setup` and makes no platform changes until setup is done. It never invents a CPA, ROAS, CTR or budget target.

## Where it comes from

| Client | How to install |
| --- | --- |
| Claude Code | The `adsmcp` plugin (`/plugin install adsmcp@adsmcp-marketplace`), or `node ./bin/adsmcp-agent.mjs install --client=claude`. |
| Codex, OpenClaw | `node ./bin/adsmcp-agent.mjs install --client=codex` or `--client=openclaw` (copies the agent into `~/.agents`). |
| Cursor, Gemini CLI | The ADSMCP checkout's `.cursor/settings.json` / `.gemini/settings.json` point at the same agent and skills. |

Run the installer from a checkout of the ADSMCP repository. Details: [MCP configuration](/mcp-setup#agent-pack-skills-and-slash-commands).

The five commands are described on [Workflows](/workflows) and [Agent Skills](/agent-skills).
