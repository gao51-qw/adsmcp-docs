ADSMCP is an MCP server and dashboard for paid media. It supplies ad-account data, analysis and safe change proposals to the AI client you already use. The AI model is always your own: ADSMCP does not provide or pay for a model. The tools are exposed over MCP and over `POST /api/v1/tools/{name}/execute`; the [API reference](/api-reference/introduction) lists every one.

## Supported now

- **Ad platforms.** Google Ads, Meta Ads, Amazon Ads, TikTok Ads, LinkedIn Ads and ChatGPT Ads. Connect them on [Connections](/connections).
- **Google Ads.** Search, Performance Max, Display, YouTube, Demand Gen, Shopping and App campaign creation (paused), ad groups, responsive search ads, keywords and negatives, assets and extensions, audiences, conversions, and reporting.
- **Meta, Amazon, TikTok, LinkedIn.** Account and performance reads, diagnostics, and the create and update tools listed on each platform page.
- **ChatGPT Ads.** Reads of accounts, campaigns, ad groups, ads and performance; pause, resume, and budget or bid changes for existing objects.
- **Measurement.** Google Analytics 4 reads. Klaviyo reads lists, segments, metrics, campaigns and flows, and can stage one campaign draft.
- **Workflows.** Setup, performance review, ad copy guidelines, wasted spend, and paused campaign creation. See [Workflows](/workflows).
- **Operations.** Pending Actions, the execution queue, a dead-letter queue, monitors, scheduled briefs, automation rules, and the Watch Agent scan.
- **Clients.** Any MCP client that can reach `https://mcp.adsmcp.si/mcp`. See [AI clients](/ai-clients).

## How changes work

- **Every change waits for a person.** Creates, pauses, enables, budget, bid and status changes are staged as pending actions. Only a person approves them, on the dashboard [Approvals](https://adsmcp.si/dashboard/approvals) page. MCP and REST can view or reject, never approve.
- **Creates are paused or drafts.** Nothing starts spending when a create runs.
- **Spend cap.** Budget changes and enables are checked against the account total cap you set; see [Safety model](/safety#spend-cap).
- **Deletes need confirmation.** `remove_*` and `delete_*` tools require `confirm_delete: true`, then approval.
- **No unattended retries.** A change that fails when it runs stops and shows in the execution queue.

## Not supported

- **ChatGPT Ads creation.** Creating ChatGPT Ads campaigns, ad groups, ads, audiences or conversion settings is not supported yet.
- **Microsoft Advertising, Snap Ads, Google Search Console, Google Tag Manager.** Not connected platforms.
- **Direct platform calls from the chat client.** Platform APIs are only called inside the MCP service.
- **A default KPI.** Missing targets stop the comparison. The agent does not invent a CPA or ROAS.
- **A built-in AI model.** Copy, summaries and recommendations in prose come from your own AI client.
- **Translated product UI.** The interface is in English.

Tools that older versions of these docs described but ADSMCP does not have are listed under **Not supported yet** in the [API reference](/api-reference/introduction), each with the tools to use instead.

## Creative and billing boundaries

The agent can draft copy with your model and stage a paused creative. ADSMCP does not print invoices, change your ad-platform payment method, or replace a designer. Plan changes happen on [Usage & Billing](https://adsmcp.si/dashboard/billing).
