Start here for account work: the first read of a session. One call reads every connected ad platform (Google, Meta, TikTok, LinkedIn, Amazon, ChatGPT and Microsoft Ads) for your connected, active accounts and counts as one tool call however many platforms it reads, so use it instead of reading each platform one by one. Returns per platform and account: spend, clicks, conversions, CPA and ROAS (where the platform reports a conversion value) for the last `days` complete days (default 7) and the `days` before, with the change in percent; up to 5 campaigns per platform that spent without a conversion; a status per platform (ok, not_connected, needs_reconnect, or error with its code: a platform that fails has no numbers, the others still answer); and next_steps, the tools to call next. Amounts stay in each platform's own currency and are never added across currencies. Read-only.

**Platform:** Meta Ads · **Type:** Read
