| Term | Definition |
| --- | --- |
| MCP | Model Context Protocol. The ADSMCP endpoint is `https://mcp.adsmcp.si/mcp`. |
| Tool | One operation in the ADSMCP catalog, callable over MCP and over `POST /api/v1/tools/{name}/execute`. See the [API reference](/api-reference/introduction). |
| Read | A tool that returns data and changes nothing. |
| Change | A tool that would change an ad account. It is never applied on the call; it becomes a Pending Action. |
| Pending Action | A staged change waiting for a person to approve or reject it on the dashboard Approvals page. MCP and REST can view or reject, never approve. |
| Paused create | A campaign, ad group, ad or creative created paused or as a draft, so it cannot spend until a later approved enable. |
| Spend cap | Your Max Daily Budget. Budget changes and enables are refused when the platform's account total daily budget would exceed it. |
| `confirm_delete` | The argument every `remove_*` / `delete_*` tool needs (`true`) before a delete can be staged. |
| Execution Queue | Approved changes and their run status. A failed run is not retried automatically. |
| Dead letter | A change whose run failed and was set aside for a person to resolve. |
| API key | A `sk_live_` (or older `pb_`) key for clients that send `Authorization: Bearer`. Created on API Tokens. |
| OAuth | Browser sign-in used by Claude, ChatGPT and local clients instead of an API key. |
| ChatGPT Ads | Ads that run inside ChatGPT. ADSMCP reads them and stages pause, resume, budget and bid changes. |
| Community plugin | A read-only JSON definition of which read tools an analysis may use. |
| Docs MCP | The Mintlify search server at `https://docs.adsmcp.si/mcp`. It answers questions about these pages and does not call ad tools. |
| Tool call | One MCP tool call or one REST execute request, counted against your plan. |
| Agent Pack | The `adsmcp` plugin and installer that add the five `/adsmcp:*` workflow commands and the performance-marketing agent. |
| Context files | `CLAUDE.md` for brand voice, `STRATEGY.md` for KPI targets, and `MEMORY.md` for confirmed outcomes. |
| Your own model | The AI model in your client. ADSMCP never supplies one. |
