Spend, impressions, clicks, CTR, purchases, CPA and ROAS per ad set within a campaign. Lists the campaign's ad sets (get_ad_sets, at most 25) and reads each ad set's own insights with get_campaign_insights (whose insights read works on any Meta object id). One sub-call per ad set, each counted against Meta quota; a failed ad set is reported and the rest continue. Ranks by ROAS (purchase value / spend) when Meta reports purchase values, else by CPA (spend / purchases), else by spend, and says which in ranked_by; entries without that metric are listed last and are not called best or worst. Read-only.

**Platform:** Meta Ads · **Type:** Read
