Change one product partition (a UNIT from get_product_groups): its max CPC bid, or include / exclude it. Switching between included and excluded re-creates the partition with the same parent and value in one approval (Google cannot change it in place), so it gets a new criterion id. Staged for dashboard approval; the approved replay re-reads the target first and refuses if it changed.
