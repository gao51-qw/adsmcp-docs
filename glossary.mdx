| Term | Definition |
| --- | --- |
| MCP | Model Context Protocol. The ADSMCP endpoint is `https://mcp.adsmcp.si/mcp`. |
| Tool | One operation in the ADSMCP catalog, callable over MCP and over `POST /api/v1/tools/{name}/execute`. See the [API reference](/api-reference/introduction). |
| Read | A tool that returns data and changes nothing. |
| Change | A tool that would change an ad account. It is never applied on the call; it becomes a Pending Action. |
| Pending Action | A staged change waiting for a person to approve or reject it, on the dashboard Approvals page or in the confirm dialog of an allowed AI client. The AI model can view or reject over MCP and REST, never approve. |
| Paused create | A campaign, ad group, ad or creative created paused or as a draft, so it cannot spend until a later approved enable. |
| Spend cap | Your Max Daily Budget. Budget changes and enables are refused when the platform's account total daily budget would exceed it. |
| `confirm_delete` | The argument every `remove_*`, `delete_*` and `archive_*` tool (and their `batch_` forms) needs (`true`) before a delete can be staged. |
| Execution Queue | Approved changes and their run status. A failed run is not retried automatically. |
| Dead letter | A change whose run failed and was set aside for a person to resolve. |
| API key | A `sk_live_` (or older `pb_`) key for clients that send `Authorization: Bearer`. Created on API Tokens with an expiry and a read or full permission. |
| Read key | An API key that can call read tools and listing tools only; anything else is refused with `permission_denied`. |
| OAuth | Browser sign-in used by Claude, ChatGPT, Cursor, VS Code and local clients instead of an API key. |
| Active account | A connected ad account that tools may use. Your plan sets how many per platform; the others stay connected but inactive. |
| Yearly pool | The tool calls of a yearly plan for the whole subscription year. |
| Fair-use limit | The most tool calls an account can make in a UTC day (1,000; 100 during the trial) or month (10,000). It stops runaway agents; nothing is charged at the limit. |
| Free trial | The first 7 days of a first subscription (14 through a referral). A card is needed; it is charged when the trial ends unless you cancel. |
| Team | Several ADSMCP users on one owner's subscription, each with their own login and connections. |
| Shared dashboard | A no-login, read-only `/d/<token>` link with live performance numbers. |
| Prompt Engineering Playbook | A $39 per-account kit (skill, instructions, prompts) built from one Google Ads account's data. |
| ChatGPT Ads | Ads that run inside ChatGPT. ADSMCP reads them and stages pause, resume, budget and bid changes. |
| Community plugin | A read-only JSON definition of which read tools an analysis may use. |
| Docs MCP | The Mintlify search server at `https://docs.adsmcp.si/mcp`. It answers questions about these pages and does not call ad tools. |
| Tool call | One MCP tool call or one REST execute request, counted against your plan. |
| Skill | An instruction file (Agent Skills format) that tells your AI client which ADSMCP tools to call and when to stop for approval. |
| Agent Pack | The `adsmcp` plugin and installer that add the five `/adsmcp:*` workflow commands, ADSMCP's skills and the performance-marketing agent. |
| Context files | `CLAUDE.md` for brand voice, `STRATEGY.md` for KPI targets, and `MEMORY.md` for confirmed outcomes. |
| Your own model | The AI model in your client. ADSMCP never supplies one. |
