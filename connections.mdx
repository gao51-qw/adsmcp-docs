ADSMCP reads an ad account, and stages changes to it for your approval, only after a person connects it. Agents start with `get_connections_status` and stop platform work when the account they need is missing.

## Connect an account

1. Open [Connections](https://adsmcp.si/dashboard/connections).
2. Choose the platform and finish its OAuth prompt, or paste its API key or token (ChatGPT Ads, Klaviyo, HubSpot).
3. Return to the dashboard and confirm the account is listed.
4. Ask the agent to call `get_connections_status` before any platform tool.

API tokens do not replace this step. A token authenticates the MCP client. The ad account connection authorizes that tenant to call the platform.

## Platforms

| Platform | How it connects | What the agent may do first |
| --- | --- | --- |
| Meta Ads | OAuth from Connections. Requested scopes include `ads_read`, `ads_management`, `business_management`, `read_insights`, `pages_manage_ads`, `leads_retrieval`, and `catalog_management`. | Read accounts and insights. Campaign creates stay paused. |
| Google Ads | OAuth with the `adwords` scope, for a manager account or a client account. Google's sign-in can ask for a passkey first. | Discover accounts, report performance, and validate drafts. |
| TikTok Ads | OAuth. The adapter expects `ads.read` and `ads.write`. | Audience, asset, and draft checks. Creates stay paused or approval-required. |
| LinkedIn Ads | OAuth. Re-authorize if the token is missing ad account scopes. | Account discovery, audience estimate, and paused creation. |
| Amazon Ads | OAuth, then `get_amazon_profiles` to pick a profile. | Paused Sponsored Products, Brands, or Display creates, plus campaign performance reports. |
| ChatGPT Ads | Paste the account's ChatGPT Ads API key on Connections (one key per ad account). | Read campaigns, ad groups, ads, performance, audiences and pixels. Creates (paused), launches, setup and pause, resume, budget or bid changes go through approval. |
| Microsoft Ads | Microsoft sign-in from Connections. ADSMCP adds one connection per active ad account the sign-in can reach. | Read accounts, campaigns, ad groups, ads, keywords and targeting. Creates (paused) and changes go through approval. |

## Google integrations (read-only)

Under **Google integrations** on Connections, **Google Analytics 4**, **Google Search Console** and **Google Tag Manager** connect with your Google login and a read-only permission for that product only (`analytics.readonly`, `webmasters.readonly`, `tagmanager.readonly`). After Google sign-in, every GA4 property, Search Console site or Tag Manager account the login can read is found and listed, up to 500; a login that reaches more is refused and nothing is connected. If exactly one is found it is enabled automatically; with more, you choose which ones your AI may use in the **Active accounts** card on Connections (any number, no plan cap). The card on each integration shows how many are connected and how many are enabled. Reconnecting keeps your choices; newly found items start not enabled. A tool call for an item that is not enabled returns `not_enabled` with a link to choose. ADSMCP never writes to these products. See [Google Analytics 4](/marketing-stack/google-analytics), [Google Search Console](/marketing-stack/google-search-console) and [Google Tag Manager](/marketing-stack/google-tag-manager).

## API key connections

Under **API key connections** on Connections, ChatGPT Ads, Klaviyo and HubSpot connect with a key or token you paste. ADSMCP checks it with the platform, stores it encrypted in Supabase Vault, and never shows it again.

- **ChatGPT Ads:** one key per ad account. See [ChatGPT Ads](/ad-platforms/chatgpt-ads).
- **Klaviyo:** your own Klaviyo private API key, one per ADSMCP user. Teammates do not share it, and there is no server-wide Klaviyo key: without your key the Klaviyo tools refuse. See [Klaviyo](/marketing-stack/klaviyo).
- **HubSpot:** the access token of your own HubSpot private app, one per ADSMCP user, read-only (contacts and deals). Teammates do not share it, and there is no server-wide HubSpot token. See [HubSpot](/marketing-stack/hubspot).

Key attempts are limited to 10 per user every 15 minutes for each of the three platforms, successful or not.

Google Analytics 4, Search Console, Tag Manager, Klaviyo and HubSpot are measurement, search, tag, email and CRM integrations. They are not ad accounts and do not count toward active accounts.

## Active accounts

You can connect any number of ad accounts, but tools can only use **active** ones: up to 5 per platform. Choose them in the **Active accounts** card on this page. A call naming an inactive account is refused with `ad_account_inactive` and not counted. The same card lists Google Analytics 4 properties, Search Console sites and Tag Manager accounts; for those you enable any number, or none (see [Google integrations](#google-integrations-read-only)). See [Multiple accounts](/accounts#active-accounts).

## If a platform is disconnected

The agent must not call that platform's tools, and it must not invent a default account id. Send the user back to Connections, then run `get_connections_status` again.
