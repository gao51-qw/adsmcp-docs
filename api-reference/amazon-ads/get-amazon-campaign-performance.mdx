Amazon performance per campaign (impressions, clicks, cost, purchases, sales, CTR, CPC, CVR, ACOS, ROAS) with totals, from live Amazon Reporting v3 reports via get_amazon_campaign_metrics (14-day attribution). Default window: the last 30 complete days; lookback_days or start_date/end_date up to 93 days (read as up to 3 reports). Reports are asynchronous: a product Amazon has not finished is returned as status 'pending' with continue_with and NO metrics; call again with that ad_product and continue_with. Without ad_product, SP, SB and SD are each requested (three reports) and tagged with their ad_product. campaign_ids keeps only those campaigns; ACOS and ROAS are null when there is no sales or no cost.

**Platform:** Amazon Ads · **Type:** Read
