Add a custom MCP connector named `adsmcp`.

- URL: `https://mcp.adsmcp.si/mcp`
- Transport: streamable HTTP
- Header, when Muse asks for one: `Authorization: Bearer YOUR_API_TOKEN` from [API Keys](https://adsmcp.si/dashboard/api-tokens)

Muse reviews performance, reads account data, and can draft a paused campaign. It uses the same catalog as every other client. Ask for the workflow by name. The order is [Workflows](/workflows). Spend-affecting changes wait in [Approvals](/approvals).

## If the call is refused

Allowed browser origins are `claude.ai`, `claude.com`, `cursor.com`, `localhost`, `127.0.0.1`, their subdomains, and the MCP host. If Muse sends another `Origin`, the server returns HTTP 403, JSON-RPC `-32001`, reason `forbidden_origin`. Omitting `Origin` passes that check.

A missing bearer after the handshake is HTTP 401, reason `missing_token`. A token in the query string is `query_token_not_allowed`. See [MCP protocol](/mcp-protocol).

First request: see the [quickstart](/quickstart).
