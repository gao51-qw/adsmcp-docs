Two credentials are involved, and they are not interchangeable.

| Credential | What it proves |
| --- | --- |
| MCP sign-in (OAuth or API key) | The AI client may call `https://mcp.adsmcp.si/mcp` for your ADSMCP account. |
| Ad account connection | Your ADSMCP account may read, or stage changes for, a specific Google, Meta, Amazon, TikTok, LinkedIn or ChatGPT Ads account. |

Connecting ChatGPT as an AI client does not connect an ad account. Finish both. See [Connect ad accounts](/connections).

## OAuth (Claude, ChatGPT, local clients)

Clients that support MCP OAuth only need the server URL:

```text
https://mcp.adsmcp.si/mcp
```

The client opens a browser, you sign in to ADSMCP and choose **Allow** or **Deny**, and the client stores its own session.

- OAuth works for **Claude** (claude.ai, Claude Desktop, Claude Code, Cowork), **ChatGPT**, and clients that receive the callback on your own machine (`localhost` / `127.0.0.1`). Other clients' callback addresses are not accepted, so they use an API key.
- Authorization codes expire after 10 minutes, access tokens after 1 hour, refresh tokens after 30 days. PKCE (S256) is required; clients register themselves with dynamic client registration.

## API keys (every other client)

Create a key on [API Tokens](https://adsmcp.si/dashboard/api-tokens) and send it as a header:

```text
Authorization: Bearer sk_live_...
```

- New keys start with `sk_live_`. Keys issued earlier start with `pb_` and keep working.
- Each key is **read** or **full**. Use a read key for reporting-only clients.
- Keys do not expire. Revoke a key on the same page to stop it. You can have up to 50 active keys.
- The key is a secret. Put it in the client's config or an environment variable, not in a prompt, screenshot or repository.

Cursor, Windsurf, Codex, Gemini CLI, OpenClaw, Perplexity, Manus, Muse, Grok and scripts calling the [REST API](/api-reference/introduction) use an API key. Clients that cannot send a header can run the local [STDIO proxy](/mcp-setup#stdio-proxy), which adds it for them.

## What a successful call looks like

`get_connections_status` returns the platforms connected for your account. `get_usage_status` returns your plan's usage. A `401` means the OAuth session or API key was missing or rejected. A connected platform can still fail later if its own grant expired; reconnect it on [Connections](https://adsmcp.si/dashboard/connections).

Signing in never approves anything. Changes are always approved by a person on the dashboard; see [Safety model](/safety).
