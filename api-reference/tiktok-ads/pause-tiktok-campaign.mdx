Pause TikTok campaigns with update_tiktok_campaign_status (operation_status DISABLE). Give campaign_id or up to 20 campaign_ids. status is optional and must be DISABLE (the other direction is resume_tiktok_campaign; DELETE is not done here). Single step. TikTok status changes are queued for approval (execution_mode approval_required, the only mode accepted): the result is returned as staged and the campaigns change only after a person approves the queued update_tiktok_campaign_status action on the dashboard.
