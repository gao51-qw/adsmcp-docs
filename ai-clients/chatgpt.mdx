## Setup

**Custom MCP server (recommended)**

ChatGPT talks to `mcp.adsmcp.si` directly, so you get every tool without waiting on a plugin review: Amazon Ads, ChatGPT Ads, Google Analytics, Google Search Console, and whatever ships next. ChatGPT saves it as a plugin of your own.

**1. Open Plugins → Add → Add custom MCP server**

In ChatGPT, click **Plugins** in the left sidebar. Click **Add** in the top right and choose **Add custom MCP server**.

![ChatGPT Plugins page with the Add menu open, showing Create plugin, Upload plugin archive, and Add custom MCP server](/images/xPeUNeB1sfjBaY7j/images/chatgpt/add-menu.png)

Plugins → Add → Add custom MCP server

> [!NOTE]
>
> Don't see **Add custom MCP server**? On Business and Enterprise, your workspace admin controls custom MCP servers. Ask them to allow it.

**2. Fill in the form**

| Field | Value |
| - | - |
| **Icon** | Optional. PNG only, 10 KB max. It only changes how the plugin looks in your sidebar. |
| **Name** | `ADSMCP-Custom`. Any name works, and it's what you'll @mention in chats. |
| **Description** | Optional, e.g. `Google, Meta, Amazon, LinkedIn, TikTok, ChatGPT Ads` |
| **Connection** | Keep **Server URL** selected (not **Tunnel**) and paste `https://mcp.adsmcp.si/mcp` |
| **Authentication** | **OAuth** |

Leave **Advanced OAuth settings** alone. ChatGPT discovers the right values from the server.

![ChatGPT Add custom MCP server form with Name ADSMCP-Custom, Connection set to Server URL https://mcp.adsmcp.si/mcp, Authentication OAuth, the 'Custom MCP servers introduce risk' warning, the ticked 'I understand and want to continue' checkbox, and the Create as a plugin button](/images/xPeUNeB1sfjBaY7j/images/chatgpt/add-custom-mcp-server.png)

The Add custom MCP server form, filled in

**3. Tick the box and click Create as a plugin**

Tick **I understand and want to continue**, then click **Create as a plugin**.

> [!WARNING]
>
> ChatGPT shows **Custom MCP servers introduce risk** for every server it hasn't reviewed. That's expected for this path. It's the same ADSMCP server that powers the plugin in ChatGPT's directory. You sign in on adsmcp.ai with OAuth, and ChatGPT never sees your ad-platform passwords.

**4. Connect the plugin**

ChatGPT opens your new plugin's page. It lists you as the developer because it's your own private plugin. Click **Try in chat**, then click **Connect ADSMCP-Custom** (or whatever you named it) in the dialog that opens.

![ChatGPT Connect ADSMCP-Custom dialog explaining what ChatGPT shares with the app, with Connect ADSMCP-Custom and Cancel buttons](/images/xPeUNeB1sfjBaY7j/images/chatgpt/custom-connect-dialog.png)

ChatGPT asks you to connect the plugin you created

**5. Authorize ChatGPT on ADSMCP**

Your browser opens ADSMCP. Sign in, or create a free account. New accounts connect their first ad platform on the way. You land on **Authorize ChatGPT**, which lists what ChatGPT will be able to do: view your campaigns, create and manage campaigns, view performance metrics, and view your connected ad accounts. Click **Authorize**, then return to ChatGPT.

![ADSMCP Authorize ChatGPT screen showing the signed-in account, the four permissions ChatGPT is requesting, the requested scopes, and the Authorize button](/images/xPeUNeB1sfjBaY7j/images/chatgpt/authorize-chatgpt.png)

ADSMCP's Authorize ChatGPT screen

**6. Start managing ads**

Start a new conversation. Mention the plugin by the name you gave it, or just ask about your campaigns.

```
@ADSMCP-Custom check my connected ad platforms
```

You should see a table of your connected accounts across all platforms with account IDs, names, and connection status. To add more ad accounts later, go to [adsmcp.ai/connections](https://adsmcp.si/dashboard/connections).

> [!TIP]
>
> You're connected directly to ADSMCP's server. Every tool on this page is available, including Amazon Ads, ChatGPT Ads, Google Analytics, and Google Search Console, and new ones appear as soon as they ship.

## FAQ

> **Which should I use — the plugin or a custom MCP server?**
>
> The custom MCP server. The ADSMCP plugin in ChatGPT's directory is having issues right now, and it's missing **Amazon Ads**, **ChatGPT Ads**, **Google Analytics**, and **Google Search Console**. The custom server connects to the same ADSMCP account and the same server, so nothing about your ad platform connections changes, and it gets new tools the day they ship.

> **Can I have both installed at once?**
>
> Yes. They share one ADSMCP account and one tool-call quota. If both are installed, @mention your custom server by name so ChatGPT doesn't pick the plugin. If the plugin keeps getting in the way, disconnect it under **Settings → Plugins**.

> **Why does ChatGPT warn that custom MCP servers introduce risk?**
>
> ChatGPT shows that warning for every server it hasn't reviewed, so it appears for any custom MCP server. It's the same ADSMCP server that backs the reviewed plugin. Authentication is OAuth: you sign in on adsmcp.ai, approve ChatGPT on the **Authorize ChatGPT** screen, and ChatGPT holds a token, not your Google, Meta, or Amazon passwords.

> **I installed the plugin and ChatGPT can't find any Amazon Ads, ChatGPT Ads, or Google Analytics tools.**
>
> That's expected. The plugin listing hasn't been updated since those shipped. Follow the **Custom MCP server** tab above. It takes about two minutes, and then the tools are there.

> **ChatGPT says a required tool isn't available and stops mid-task.**
>
> ADSMCP asks your assistant to look up a tool's exact parameters with `get_tool_schema` before calling it — that's what stops it inventing an argument. The plugin's tool list is fixed at the version OpenAI last approved, and on some installs `get_tool_schema` isn't in it, so ChatGPT would report a required tool as missing and stop.
>
> It now works around it on its own: the assistant is told to fetch the schema through a platform router instead, which returns the same thing. If an older chat still gets stuck, start a new one so ChatGPT picks up the current instructions. A custom MCP server never hits this — it always carries the current tool list.

> **What are ChatGPT plugins? Are they the same as apps?**
>
> Yes. OpenAI renamed ChatGPT **apps** to **plugins**, and the App Store is now the **Plugins** directory. A custom MCP server you add is saved as a plugin of your own, which is why ChatGPT lists you as its developer. Plugins let ChatGPT securely connect to external services using the Model Context Protocol (MCP), the same open standard Claude uses. ADSMCP's plugin manages advertising across Google Ads, Meta Ads, Amazon Ads, ChatGPT Ads, LinkedIn Ads, and TikTok. If you're weighing apps against a Custom GPT, see [ChatGPT Apps vs Custom GPTs for Advertising](https://adsmcp.si/blog/chatgpt-apps-vs-custom-gpts).

> **Which ChatGPT plans work with ADSMCP?**
>
> Every plan, including Free. You add the custom MCP server the same way on Free, Plus, and Pro. On Business and Enterprise, your workspace admin controls custom MCP servers, so ask them if **Add custom MCP server** is missing from the **Add** menu on the Plugins page.

> **How is ChatGPT different from Claude for ads?**
>
> Both use the same ADSMCP MCP server, so functionality is identical. However, ChatGPT may be more conservative in automatically calling tools — you might need to explicitly mention which tool to use. Claude (created by Anthropic, who also created MCP) tends to invoke tools more naturally and supports progress streaming.

> **Can I use ADSMCP with both ChatGPT and Claude?**
>
> Yes. Your ADSMCP account works everywhere. Add ADSMCP as a custom MCP server in ChatGPT and install the Anthropic-verified ADSMCP connector in Claude, and add ADSMCP in Cursor, Grok Bot, Claude Code, Perplexity, or any MCP-compatible client. Your ad account connections carry across all of them.

> **How much does this cost?**
>
> ADSMCP pricing is based on tool calls, not ad spend. Free tier: 15 calls/month. Plus: $49/mo for 150 calls. Pro: $99/mo for 600 calls. Max: \$199/mo for 3,000 calls. See [full pricing](https://adsmcp.si/pricing).

> **Tools aren't working or I see connection errors. What do I do?**
>
> If no ADSMCP tools work at all (even basic ones like checking connections), follow these steps:
>
> 1. **Check tool permissions:** In **Settings → Plugins**, set your ADSMCP plugin to **Allow low-risk tools**, so read tools run on their own and changes still ask first, or to **Always ask**. If you blocked tools by accident, reset the permission there.
> 2. **Reconnect:**
>    * *Custom MCP server* — **Settings → Plugins**, remove the plugin you created, then **Plugins → Add → Add custom MCP server** again with `https://mcp.adsmcp.si/mcp` and sign in.
>    * *ADSMCP plugin* — the plugin is having issues right now. Disconnect it in **Settings → Plugins** and add the custom MCP server instead.
> 3. **Refresh your ADSMCP session:** Go to [adsmcp.ai](https://adsmcp.si), log out, log back in, then return to ChatGPT.
>
> ChatGPT plugins may disconnect every 1–2 weeks — this is normal. Just reconnect and re-authenticate when it happens.
>
> See [Troubleshooting FAQ](/knowledge-base/faq#troubleshooting) for more details.
