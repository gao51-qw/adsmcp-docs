---
title: "OpenClaw"
description: "Add the ADSMCP remote MCP server to OpenClaw and use the five workflow names."
---

```bash
openclaw mcp add adsmcp --url https://mcp.adsmcp.si/mcp
```

OpenClaw uses the same workflow names as Codex:

- `/adsmcp:setup`
- `/adsmcp:performance-review`
- `/adsmcp:write-ad-copy`
- `/adsmcp:wasted-spend`
- `/adsmcp:campaign`

Ad operations go through ADSMCP tools and [Approvals](/approvals). OpenClaw does not call Meta, Google, TikTok, LinkedIn, or Amazon hosts on its own.

If the client asks for a header, use a token from [API Keys](https://adsmcp.si/dashboard/api-tokens). First request: see the [quickstart](/quickstart).
