Launch a Meta carousel campaign, created PAUSED: create_campaign (with the daily budget) -\> create_ad_set (targeting) -\> create_ad with an inline carousel (link_data.child_attachments, 2-10 cards) creative, each step using the id the previous one returned. Objectives: OUTCOME_TRAFFIC, OUTCOME_AWARENESS, OUTCOME_ENGAGEMENT, and OUTCOME_SALES / OUTCOME_LEADS with pixel_id (the ad set optimises for that pixel event; app promotion is not offered). Meta writes go through the approval queue: the tool stops at the first step that is queued (normally create_campaign) and returns the remaining steps; after approval, use the id Meta returned for the approved step in place of each \{"$fromStep": n\} reference. The Meta campaign workflow (get_connections_status, get_ad_accounts, validate_campaign_draft) still applies to create_campaign.
