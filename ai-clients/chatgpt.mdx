ChatGPT is a client. ADSMCP does not buy or measure ads that run inside ChatGPT.

## Add the connector

1. Settings, then Apps, then Advanced settings. Turn on developer mode.
2. Create a connector named ADSMCP.
3. Server URL: `https://mcp.adsmcp.si/mcp`.
4. If the form asks for a header, create a token at [API Keys](https://adsmcp.si/dashboard/api-tokens) and set `Authorization: Bearer YOUR_API_TOKEN`.

Developer mode and that URL are the setup. ChatGPT does not install the slash-command pack. Say the workflow in a sentence, for example "Run the performance review and do not change any budget." The tool order is still the one in [Workflows](/workflows).

## If the call is refused

Allowed browser origins are `claude.ai`, `claude.com`, `cursor.com`, `localhost`, `127.0.0.1`, their subdomains, and the MCP host itself. A ChatGPT page origin is outside that list. If the connector sends that `Origin`, the server returns HTTP 403, JSON-RPC `-32001`, reason `forbidden_origin`. A request that omits `Origin` passes this check.

A missing bearer after the handshake is HTTP 401, reason `missing_token`. A token in the query string is `query_token_not_allowed`. See [MCP protocol](/mcp-protocol).

Writes still stop in [Approvals](/approvals). First request: see the [quickstart](/quickstart).
